# 题级教师稳定性蒸馏：初期加权训练计划

**日期：** 2026-10-24  
**状态：** 已讨论的初期实验计划；本文不表示训练代码已实现或实验已运行。  
**承接：** [TSW v2 动机与探针记录](https://github.com/LeiGong0125Carrot/OPD-Aha-Floor/blob/d5e9d31ec6dfff9ce9d790560b5f2882f17e0a44/teacher_stability/tsw_plan.md)。  
**本轮优先级：** 直接开展题级加权训练，用匹配对照检验效果；不再将额外的 prefix 可靠性探针、hidden intervention、层扫描或少标签学习曲线列为开训前置条件。

> 本文件单独保存最新的初期训练设计，不覆盖 `tsw_plan.md` 中已有的采样、探针和历史计划记录。本轮实验矩阵、权重定义和 checkpoint 比较口径以本文件为准。`probing_plan.md` 中的额外研究探针保留为后续可选分析，而非本轮必须完成的闸门。

## 1. 核心问题与研究边界

第一轮只回答三个问题：

1. 对低稳定性题目的教师监督，正常学习、降低权重、完全置零，哪一种更有利于学生训练？
2. 收益是否依赖教师稳定性与题目的对应关系，而不只是任意非均匀加权或随机丢弃监督？
3. 有效规则成立后，生成前教师 hidden 分数能否替代多次教师采样来分配监督？

**工作假设：** 冻结特权教师对不同题目的判断稳定性不同。其答案一致性及生成前表示预测分数，可以作为不依赖答案 GT 的题级监督分配信号。降低低稳定性题目的相对蒸馏强度，可能比所有题统一强度更有效。

这不是以下主张：

- 稳定教师一定正确，或者每个 token 都值得模仿；
- 低稳定性题目只产生错误梯度或没有任何学习价值；
- probe 直接预测真实正确性、边际学习收益或同题各条轨迹的质量；
- 硬置零和等权构成性能的数学上下界。

**置零、半权重、全权重是监督强度的实验端点。** 性能是否提高以及有效区间有多大，由训练结果决定。

### 1.1 固定不变的部分

- **题级分配：** 同题所有 student rollouts 共享一个权重，不按其答案是否符合教师多数票继续筛选。
- **目标不变：** 保持原有教师条件分布和 top-100＋尾桶 JSD，不重构 token target。
- **学习流程不变：** 学生照常 on-policy 生成与更新，不引入 hidden MSE、token-level gating 或学生侧可靠性选择器。
- **GT 边界：** 答案 GT 不进入 probe 训练、权重计算、低分集合或随机集合的选择。GT 仅用于结果评测和冻结后的诊断。沿用现有 bbox/crop 信息，不把“无需答案 verifier”表述成“无需任何标注”。
- **无需额外机制证明后才开训：** student-prefix 监督失真可以解释结果，但不是当前题级加权假设的前置探针。

## 2. 相关工作与本轮借鉴点

本节保留前述文献讨论对设计的启发，不把他文的阈值、最佳结果或任务结论当成本实验已证实的事实。论文来源链接用于后续精读；本文件不以会议身份或“首次提出”作为方法成立的依据。

| 工作 | 本轮借鉴的设计原则 | 与本设置的区别／不能直接照搬之处 |
| --- | --- | --- |
| [GATES: Self-Distillation under Privileged Context with Consensus Gating](https://arxiv.org/html/2602.20574) | 特权教师答案共识可以控制题级学习；将低共识题零损失作为明确基线。其 on-policy 分支在题目通过门控后不再按学生答案逐条过滤。 | 文档特权信息、教师更新方式及训练组合不同；本轮仅采用 frozen visual teacher 的题级控制，不宣称复现完整 GATES。 |
| [FiRe-OPD: Filter, Then Reweight](https://arxiv.org/html/2606.02684v2) | 分别控制监督筛选与加权强度；比较硬／软策略，并分析过滤比例过强或过弱的影响。 | 其生成后轨迹评分和 token 加权不等于生成前题级稳定性；不能继承其最优过滤比例。 |
| [CaRE-KD: Distilling What Matters](https://arxiv.org/html/2609.36734v1) | 将是否接受教师监督与如何匹配分布区分开；教师监督不应被默认等量信任。 | 不在首轮引入额外师生相对不确定性估计或修改散度。 |
| [EOPD: Entropy-Aware On-Policy Distillation](https://proceedings.mlr.press/v306/jin26e.html) | 不确定性不一定无用，故软降权和完全拒绝应同时比较。 | token-level entropy 与最终答案一致性不是同一个量；保持当前 JSD，不移植 KL 组合。 |
| [Semantic Entropy Probes](https://arxiv.org/html/2406.15927) | 用采样不确定性标签训练 hidden probe，支持生成前低成本预测这一技术路线。 | 不是 OPD 加权有效性的证据；semantic entropy 不等于 det4 或多数答案占比。 |
| [TrustMOPD](https://arxiv.org/html/2609.23697) | 使用与题目／状态无关的随机权重对照，区分任意加权和信号对应关系的作用。 | 只借鉴对照原则，不复制其多教师 token-level 方法。 |

结论：选择性蒸馏已有先例；当前应检验的是**视觉特权 OPD 下，生成前题级稳定性分数是否适合分配监督**，而不是再提出一个未经控制的复杂权重函数。

## 3. 固定实验设置与已有信号

### 3.1 训练设置

沿用 TSW v2 的主体配置，只增加独立实验开关，不修改仓库默认 OPD-Aha recipe。

| 项目 | 本轮设置 |
| --- | --- |
| 数据 | Vision-OPD-6K / off6k，6241 题 |
| 模型 | Qwen3.5-4B base；教师使用冻结 base checkpoint |
| 学生视图 | 带红框全图＋既有提示语 |
| 教师视图 | crop-only，沿用 `bbox_images` 和 `swap_images` 路径 |
| 蒸馏目标 | top-100＋尾桶 JSD，混合参数 alpha = 0.5 |
| Student rollout | 每题 2 条；temperature = 1，top_p = 1，max_tokens = 1024 |
| 优化 | learning rate = 2e-6；batch = 48；mini-batch = 48 |
| 预算 | 固定 130 training steps；沿用现有三卡配方，ULYSSES_SP = 1 |
| 不叠加 | PBD、null target 重构、hidden loss、token gate、student-side gate |
| 评估 | V*、ZoomBench、HR-4K、HR-8K；沿用已有 judge 和 pure-llm 评分口径，记录版本 |

### 3.2 主信号：教师 L28 折外分数

使用现有教师视图 prompt 末 token 的 L28 线性 probe，输出按图片分组交叉拟合的 det4 分数：

\[
r_i=p_{\psi}^{\mathrm{OOF}}
\big(\mathrm{det4}=1\mid h_{T,i}^{L28,\mathrm{prompt\ end}}\big).
\]

- 每题分数来自没有用该图片组训练的 probe；预处理和正则选择也必须遵守同一分组边界。
- 教师冻结、prompt 与图像处理固定，分数预先计算并在训练期间冻结。
- 第一轮**仅使用排序，不直接使用原始概率作为损失权重**，避免把排序质量与概率尺度／校准混在一起。
- 不基于答案 GT 重新挑层或修改 probe；L28 沿用当前已讨论的稳定性任务选择。

### 3.3 开训前的数据口径检查，不是新增研究探针

- 明确并保存 det4 的准确代码定义：四次全部有效且一致，或至少三个有效且有效答案一致，不能在报告中混用。
- 明确 det4 无效标签、解析失败、截断的处理；不将解析失败当作一个一致的答案类别。
- 区分后四次平均正确率、至少两次答对、至少三次答对等诊断字段。
- 导出全题 OOF 分数、fold/group ID、有效性标记和源数据版本；与历史 summary 核对。
- 题目对齐不能只靠行数一致：检查稳定题目 ID、prompt/options/image 对应关系及输入文件哈希。
- 不用 GT 选择低分组；已有 GT 字段只能作身份对齐的只读校验和离线诊断。

## 4. 首轮规则：固定最低 25%，扫描学习强度

### 4.1 固定低稳定性集合

令 \(N=6241\)，定义：

\[
\mathcal U_{25}
=\{\text{教师 OOF probe 分数最低的 }\lfloor0.25N\rfloor\text{ 道题}\}.
\]

因此最低分集合为 **1560 题**。25% 是预先登记的初始覆盖比例，不是已知最优阈值。

若边界分数并列，使用独立于答案 GT 的固定随机顺序打破并列，保存 seed 与题目 ID。冻结集合后，训练过程中不按新结果改动。

不直接照搬外部方法的绝对共识阈值：按 TSW v2 的频数表，教师多数次数低于 4/8 的只有 211 题，约 3.38%。同一个绝对门槛在本数据上可能只是很弱的干预。首轮用固定覆盖率来定义力度。

### 4.2 三个强度属于同一个公式

\[
\boxed{
w_i(\lambda)=
\begin{cases}
\lambda,&i\in\mathcal U_{25},\\
1,&i\notin\mathcal U_{25},
\end{cases}
\qquad\lambda\in\{1,0.5,0\}.
}
\]

- \(\lambda=1\)：等权蒸馏。
- \(\lambda=0.5\)：同一批低稳定性题半权重。
- \(\lambda=0\)：同一批低稳定性题的全部 student-rollout 蒸馏项置零。

零权重只取消这些样本的直接蒸馏梯度；模型仍可通过其他题的共享参数更新产生迁移，不能声称这部分题的能力不再变化。

### 4.3 首轮五臂

| 配置名 | 低权重题集合 | 集合内原始权重 | 其他题权重 | 主要问题 |
| --- | --- | ---: | ---: | --- |
| **V0** | 无 | 1 | 1 | 同配置等权基线 |
| **P-Soft25** | probe 最低 1560 题 | 0.5 | 1 | 低稳定性监督少学是否更好？ |
| **P-Hard25** | 同一 probe 最低 1560 题 | 0 | 1 | 完全不学是否进一步改善？ |
| **R-Soft25** | 固定随机 1560 题 | 0.5 | 1 | 收益是否需要稳定性对应关系？ |
| **R-Hard25** | 同一固定随机 1560 题 | 0 | 1 | 硬过滤是否只是任意删监督的作用？ |

**预先指定主要候选：P-Soft25。** P-Hard25 是关键端点消融，不预判哪一个一定最好。

随机集合从全体题目独立抽取，不刻意选择高分题，也不强制与低分集合互斥。R-Soft25 与 R-Hard25 共用一个随机集合；它按题静态固定，不每个 step 重抽。记录与训练 seed 分离的权重随机 seed。

五臂的原始题级权重集合成对匹配，但 token 长度与实际梯度范数未必匹配，必须记录有效 token 覆盖与权重统计。

## 5. 统一损失、归一化和 on-policy 流程

令 \(k\) 为同题 rollout，\(m_{ikt}\) 为基础 JSD 实际有效的 response-token mask，\(\ell_{ikt}\) 为未加入题级权重的 JSD。

\[
\boxed{
\mathcal L_{\mathrm{TSW}}
=
\frac{\sum_{i,k,t}w_i m_{ikt}\ell_{ikt}}
{\sum_{i,k,t}w_i m_{ikt}}.
}
\]

等价实现是先在整个全局训练 batch 上计算：

\[
N_{\mathrm{tok}}=\sum_{i,k,t}m_{ikt},\qquad
Z_w=\sum_{i,k,t}w_i m_{ikt},\qquad
\widetilde w_i=w_iN_{\mathrm{tok}}/Z_w,
\]

再用原始全局 \(N_{\mathrm{tok}}\) 聚合。**两种实现选一种，不重复归一化。**

### 5.1 保证与不保证

归一化保持有效 token 的平均权重为 1，避免简单地统一缩小蒸馏系数；**不保证实际 loss 数值或梯度范数不变**。

硬过滤低分题时，其余题获得更高的相对监督权重。因此结果解释为“监督重新分配策略有效”，不能仅据此声称“删除的都是错误梯度”。

### 5.2 预算与数据曝光控制

- 第一轮保留原始数据集、prompt 采样规则、rollout 数和训练步数，不删除低分 parquet 行、不补采高分题。
- 各臂学生正常 on-policy 采样。随着模型更新，实际 trajectories 可以不同；不为了强求相同轨迹而改成固定 base-rollout 离线训练。
- 只有题级蒸馏权重不同，其他目标与系数全部固定。若存在辅助 loss，其是否参与必须在所有臂一致并记录。
- 首轮不是 rollout 省算力实验；确认有效后，再单独研究跳过零权重题前向等系统优化。

### 5.3 最小实现检查

- 全局归一化一次完成，micro-batch／数据并行分片继承同一系数；不得逐 micro-batch 重新归一化。
- 同题两条 rollout 共享原始权重，但有效 token 数分别计入全局分母。
- 题级连续权重与二值有效性 mask 分开存储，不破坏已有 fallback 判断。
- 全一权重与原基础实现等价；最终传入的零权重样本不贡献蒸馏梯度。
- 在固定最终系数和分母时，单项梯度按系数缩放；不错误地测试“原始权重翻倍再归一化仍使该项翻倍”。
- micro-batch 切分不改变损失目标；日志中的权重均值应为 token-weighted mean。
- 当全局 \(Z_w=0\) 时不得除零；纯蒸馏更新应显式跳过，避免把优化器动量／weight decay 的变化当作零监督更新。记录这种事件及实际更新次数。

## 6. 第一轮执行与评估

### 6.1 执行顺序

1. 导出并冻结 OOF 分数、低分集合和随机集合；确认原数据与 checkpoint 版本。
2. 实现独立题级权重开关，完成 code review 与单元测试。
3. 按既有集群规范：登录节点仅做语法／轻量静态检查；模型计算和 GPU 测试在正式分配的计算资源上执行。
4. 小规模 smoke test 检查全一、半权、置零、全零保护和全局归一化。
5. **seed 42 探索轮：** 先 V0、P-Soft25、P-Hard25，再完成 R-Soft25、R-Hard25。
6. **独立 seed 123 确认轮：** 至少补 V0、主要候选及其匹配随机对照。若 Hard 是明确的下一候选，再补 Hard 与 R-Hard，而不是无条件复制整个参数网格。

单 seed 只用于探索，不能据此宣布稳定有效。第二次运行必须实际改变训练 seed，不只是添加 `r2` 文件名。随机权重集合可以固定以隔离训练重复性，但须记录该选择。

本次文档提交不等于申请资源、启动训练或安排定时任务；具体执行沿用项目的资源审批和释放流程。

### 6.2 主结果固定 checkpoint

- **主结果：统一 step 130。** 所有 benchmark 报同一 checkpoint。
- **主要性能观察：V*、ZoomBench。** HR-4K、HR-8K 用于检查泛化和困难任务退化。
- 固定中间 steps 可以评测并展示曲线，但不以不同方法各自峰值作为唯一胜负依据。
- 保存最终 checkpoint 及必要的固定中间 checkpoint；不再混用“只保留 Zoom 最优”和“按 V* 最优汇报”两套规则。
- 沿用相同 judge、提示和解码配置，记录评测版本。不得用答案 GT 为训练题挑选权重、阈值或低分集合。

### 6.3 必要记录

| 类别 | 记录项 |
| --- | --- |
| 性能 | 固定终点各 benchmark 分数；候选−V0 与候选−匹配随机对照的配对差值 |
| 监督覆盖 | 降权题目比例、有效 response-token 比例、各臂低权集合交集 |
| 权重 | 原始权重统计、全局归一化系数、token 加权均值／方差 |
| 稳定性 | 梯度范数、异常值、全零 batch、实际更新次数 |
| 行为 | 平均生成长度、答案格式失败率、答案出现位置 |
| 成本 | 分数建立和导出成本、训练 GPU-hours、每步耗时 |

配对评估尽量按题目或图片组报告不确定性；两个训练 seed 的范围只作初期描述，不替代稳定性或等效性证明。

**加权训练 loss 更低不视为成功证据。** loss 分配本身已经改变，核心结果是正常无门控推理时的任务表现。

## 7. 如何解读结果与决定是否继续

| 结果 | 当前可支持的判断 | 下一步 |
| --- | --- | --- |
| P-Soft25 优于 V0 且优于 R-Soft25 | 稳定性对应的软降权有初步价值 | 重复确认；比较采样来源 |
| P-Hard25 优于 V0 且优于 R-Hard25 | 当前设置下拒绝部分低分监督有效 | 重复确认；检查覆盖比例 |
| Soft 优于 Hard | 低分题仍可能提供有用监督 | 保留部分监督，后续考虑保底／连续权重 |
| Hard 优于 Soft | 当前干预范围内，完全拒绝优于保留一半 | 研究过滤范围，避免直接推广为“越删越好” |
| P 与相应 R 接近 | 没有充分证据表明稳定性排序优于任意分配 | 不扩大方法主张；记录有限结论 |
| P、R 都下降 | 当前覆盖比例与预算下减少监督不划算 | 不继续无边界参数搜索 |
| 收益只出现在单个峰值／单个 seed | 结果尚不稳健 | 优先重复确认，不挑峰值宣称成功 |

若 P 与 R 都优于 V0、且 P 进一步优于 R，仍可能同时存在任意加权效应与信号对应效应；不要求随机对照必须恰好落在 V0 的两次范围内。

负结果限定为当前模型、数据、分数、规则、覆盖比例和预算，不扩大为“题级教师可靠性不是瓶颈”。

## 8. 第二轮：分开研究信号来源、覆盖率和连续权重

只有第一轮显示值得继续的信号，才推进以下有限扩展，不做完整笛卡尔积扫描。

### 8.1 信号来源：probe 排序能否替代采样排序？

固定首轮有效的规则与覆盖比例。例如 Soft25 有效时：

| 配置 | 排序依据 | 低分组权重／覆盖 |
| --- | --- | --- |
| P-Soft25 | L28 OOF probe 分数 | 0.5；1560 题 |
| S-Soft25 | 1024-token 教师 8 次采样多数占比 | 0.5；1560 题 |

Hard 有效则同理比较 P-Hard25 与 S-Hard25。保留相同原始权重取值集合与匹配随机对照，尽量只改变分数与题目的对应关系。

采样分数在阈值处并列时用固定、独立于 GT 的随机次序选边界样本；保存题目 ID，恰好匹配覆盖率。

probe 不必胜过采样才有价值，但“接近”应报告配对差值及不确定性，不能仅凭两个 seed 范围重叠就宣称等效。低成本主张必须计入用于训练 probe 的采样成本。

### 8.2 覆盖范围：找经验有效区间

固定信号与降权强度，比较：

\[
\rho\in\{10\%,25\%,50\%\}.
\]

25% 已有首轮结果，仅新增其他两个覆盖比例。阈值由分数分位数和固定并列规则决定，不由训练题 GT 决定。

这回答“降权／过滤多少题合适”，不是证明某个稳定性绝对阈值以下的教师必然错误。若第一轮无可靠信号，不自动继续扫描更多覆盖率。

### 8.3 连续权重：只保留最简单的后续基线

可在有效方向明确后补：

\[
w_i=s_i.
\]

暂不同时扫描幂次、sigmoid、温度、动态课程、负权重等。若研究 probe 原始概率加权，必须另行控制其权重分布／校准差异；不能把 det4 概率与多数占比视为同一尺度。

低稳定性支持降低信任，不支持给负权重主动让学生远离教师。

## 9. 与 Vision-OPD 和 OPD-Aha 的比较

**第一目标：超过同配置等权 V0。** 与历史发布 checkpoint 的绝对分数比较不能替代这个因果对照。

有重复收益后，再加入或确认匹配条件下的 OPD-Aha 基线：

\[
\text{等权 V0}\quad\text{vs.}\quad
\text{冻结配置的 TSW}\quad\text{vs.}\quad
\text{OPD-Aha}.
\]

匹配模型初始化、训练数据、rollout 预算、评测口径，并分别报告成本。TSW 在不修改教师 target 的情况下超过 V0、接近 OPD-Aha，就有实用价值；超过 OPD-Aha 是进一步目标，不作为第一轮必须满足的条件。

不宣称首次使用教师共识门控；研究定位是视觉特权 on-policy 蒸馏中的**生成前、题级监督可靠性分配**。
