# 师生分歧门控 + 教师自生成轨迹蒸馏：计划

**日期：** 2026-10-25
**状态：** 计划记录；代码未实现，训练未开始。实现前需用户确认第 6 节的待定项。
**承接：** [TSW 首轮计划](tsw_initial_training_plan.md)（题级稳定性降权）。TSW r1 结果见第 1 节；预检代码 `OPD-Aha-sup/scripts/probe_disagree.py`（sup adba154），结果 `eval/probe_hidden/disagree_1025/`。

## 1. 动机

**TSW 首轮 r1 与 V0 打平**（gpt-oss-120b judge，pure-llm；step 60–130 八个 ckpt 平均）：

| 运行 | V* | ZoomBench | HR-4K | HR-8K |
| --- | --- | --- | --- | --- |
| V0 | 91.10 | 59.78 | 83.27 | 79.53 |
| PS（U 降权 0.5） | 90.44 | 59.23 | 82.41 | 78.75 |
| PH（U 置零） | 91.36 | 59.88 | 82.42 | 79.45 |
| RS（随机 25% 降权） | 90.18 | 59.41 | 83.11 | 79.22 |

- HR-Bench 跨实例计数题上，三个 TSW 臂都低于 V0，随机集合的 RS 也一样。所以 U 题型偏斜导致覆盖不足（假设 B）不成立。
- r2 仍在跑，按"每法两次"规则定论。

**题级降权没起作用。我们的解释是降权方向和问题所在的维度不对：**

1. **教师被学生前缀带偏（10-17 分叉探针）。** 教师自己生成时，只有 7–10% 会选学生的答案；在学生前缀下续写，这个比例升到 0.51–0.84。分叉点在 t≈0。V0 的教师只在学生轨迹上打分，所以在师生意见不同的题上，教师的真实意见基本传不给学生。
2. **分歧题恰恰是教师最该被听的题（10-25 预检，base 模型，各视图 8 样本，1024 token，T=1）。** 两视图多数答案不同（D=1）的题占 40.5%（有效 5073 题），在这些题上：
   - 教师准确率 0.638，学生 0.237，差 +0.40；一致的题（D=0）只差 +0.13。
   - D=1 内部：教师对、学生错占 81%，教师错、学生对占 10%。
   - 准确率都用样本 4..7 计算，与定义 D 用的样本 0..3 不重叠。
3. **TSW 的稳定性分数分不出分歧题（AUC 0.585）**，它和分歧是两个不同的轴。

**新假设：** 在师生分歧大的题上，把蒸馏轨迹从"学生生成、教师打分"换成"教师在自己视图下从头生成"。这样可以绕开前缀把教师带偏的问题，把教师的意见传给学生。

## 2. 分歧怎么检测（不用标签，生成前）

预检对比了几种检测信号：

| 信号 | AUC（预测 D=1） | 训练时成本 |
| --- | --- | --- |
| **t=0 读出 TV(p_S⁰, p_T⁰)**：两视图第一个回答 token 在选项字母上的分布（重归一化）之差 | **0.885**；与样本 4..7 的 TV 的 ρ = 0.58 | 每题两次 prefill，各取一个位置 |
| hidden 线性探针，L28 prompt 末位，学生视图 / 教师视图 / 两者拼接 | 0.635 / 0.675 / 0.695 | 要先离线采样生成标签再训练探针 |
| 打乱标签对照（各层取最大） | 0.49 / 0.51 | — |
| TSW 分数 1−p | 0.585 | — |

**决定：主检测器用 t=0 读出 TV，不用 hidden 探针。** 原因：

- 准确度高得多（0.885 对 ≤0.70）；
- 不需要训练探针，也就不依赖离线采样得到的标签；
- 能在训练中在线计算，跟着学生一起变。学生向教师靠拢后，分歧会缩小，静态集合会过时。

**这个信号的局限（如实记录）：**
- t=0 原始字母总质量的中位数约 0.45，近一半的采样在第一个 token 就直接给出答案。所以 t=0 TV 与"采样后多数答案不同"在机制上高度同源，更像是在提前**测量**分歧，而不是在**预测**推理过程会怎么分叉。
- 好在门控的用处已经由不重叠样本上的诊断证明：按 t0-TV 取前 25% 的题，师生准确率差 +0.489，其余题 +0.146；这部分题里教师对、学生错 1144 题，教师错、学生对只有 78 题。
- 两个视图采样都用 vLLM seed=42，分歧比例偏低估。

**hidden 探针保留作次要分析**：只回答"只看学生视图、不跑教师，能否预知分歧"。这种方式省一次教师 prefill，但 AUC 0.635 太弱，不作门控。

**计算细节：**
- p_T⁰ 来自冻结的 base 教师（裁剪图视图）。教师不更新，所以可以**离线一次算好**，预检已有 6241 题的结果。
- p_S⁰ 来自**当前学生**（红框全图 + 提示视图），每步在线算，候选做法见 6.2。
- 都在题目自己的选项字母上重归一化；未出现的选项记为 0。
- 门控统计量 g_i = TV(p_S⁰,i, p_T⁰,i)，按题计算，同一题的 n 条 rollout 共用。

## 3. 训练臂

底座、数据、超参与 TSW 首轮完全相同：off6k 6241 题，rollout_n=2，lr 2e-6，48 prompts/step，130 步，每 10 步存一次 ckpt，JSD α=0.5，top-100 加尾桶，seed 42。

| 臂 | 选题 | 被选中的题怎么处理 |
| --- | --- | --- |
| **DG**（分歧门控） | 每步 batch 内按 g_i 取最高 q=25% 的题 | 每题 n=2 条学生 rollout 中替换 1 条为教师轨迹，另 1 条保持学生 on-policy |
| **DR**（随机对照） | 每步 batch 内随机取同样比例 q 的题（不看 g，GT-free 固定 rng） | 同 DG |

- **教师轨迹从哪来：** 从冻结 base 教师在教师视图下离线生成的 8 条样本中取一条（`eval/probe_hidden/teacher_gen1024_1023/gen.json`，6241 题 × 8 条，1024 token）。
  - 只从答案等于教师 8 样本多数字母的那几条里随机选一条。这用的是教师自洽，不用 GT。
  - 没有唯一多数，或 8 条都没解析出答案时，这道题不替换。
  - 为避免和预检重叠导致乐观偏差，取样范围限定在样本 4..7（D 和 p_T⁰ 用的是 0..3 和 prompt 末位）。
- **损失：** 学生在学生视图 prompt 下前向教师轨迹的 token，冻结教师在裁剪图视图下给同样的 token 打分，用和 V0 相同的 JSD。这条轨迹本来就是教师自己生成的，所以教师在上面的分布不会被学生前缀带偏。
- **剂量对齐：** 用替换而不是新增，batch 大小和每步计算量都和 V0 相同。DG 和 DR 替换的题数相同，所以两臂的差异只来自"选了哪些题"。
- **监测（不屏蔽）：** 教师轨迹里的泄漏词（例如 "crop"、"zoomed"、"red bounding box"），统计其在替换行与非替换行中的出现率；推理期格式（缺 `<answer>` 的比例）和平均长度。
- **两臂各跑两次**（同配置 seed 42）。V0 不重训，用已有的 V0 r1（`off6kTSWv0n2`）作参照。

## 4. 判据（预先定下）

**主判据：** DG 两次运行的 step 60–130 平均，在 V\*、ZoomBench、HR-4K、HR-8K 中至少 3 项高于 DR，同时也高于 V0 r1。

**机制判据（同 ckpt，GT 只作诊断）：**
- 在训练集的高 g 题上，学生的多数答案与教师多数答案的一致率，DG 比 DR 提升得更多；
- g_i 的 batch 均值下降得更快；
- HR-Bench 跨实例计数题不低于 V0。

**否决条件：** 下面任一条出现，就判为风格污染而不是信息传递：
- 学生推理期的泄漏词率或格式漂移明显上升；
- 回答长度向教师轨迹的长度漂移，同时分数不升。

## 5. 风险与已知问题

- **离线教师轨迹是 off-policy 的。** 学生生成这种轨迹的概率可能很低。用 JSD（而不是 SFT）只对齐每个位置的分布，但学生的状态分布仍然和自己的 rollout 不一样。只替换 n=2 中的一条，是为了保留一半 on-policy 信号。
- **曾有类似的负结果。** PBD 在固定比例位置用教师续写，结果 ≈V0（V\* 92.15 / Zoom 59.41 / 4K 83.12 / 8K 79.25）。本计划和它有两点不同：从 t=0 开始用教师轨迹，而不是接在学生前缀后面续写；只用在分歧题上，而不是所有题。如果 DG 也 ≈ DR ≈ V0，说明"传递教师意见"这条路本身收益有限。
- **剂量可能偏小。** 25% 的题、每题替换 1/2 条，约等于 12.5% 的轨迹。如果第一轮看起来打平但趋势是正的，第二轮再考虑 q=50% 或 n 条全部替换；不加"A + 常数剂量"一类的对照。
- **教师视图泄漏。** 教师轨迹里会出现 "red bounding box"、对局部细节的描述等，等于把裁剪视角的说法带进学生视图。按规则只监测不屏蔽。

## 6. 待用户确认

1. **教师轨迹来源：**
   - **(a) 离线冻结 base 教师的样本（推荐）**：零额外生成成本、实现简单、教师就是打分用的那个冻结 base 模型。
   - (b) 在线生成：用当前策略在教师视图下生成，即 PBD 的做法。这时 vLLM 引擎装的是学生权重，生成轨迹的就不再是冻结 base 教师。
2. **p_S⁰ 的在线算法：**
   - **(a) 每步额外跑一次学生视图 prompt 的 1-token vLLM prefill，取 top-20 logprobs（推荐）**；
   - (b) 从 actor 计算 old_log_prob 那次前向的 prompt 末位直接读，需要改动 dp_actor 的返回值；
   - (c) 静态：直接用预检里 base 学生的 p_S⁰，作为消融。
3. **门控比例 q** 先用 25%，和 TSW 首轮保持可比。
4. 实现时：参考的开源代码（GATES 无公开代码；PBD 分支行逻辑见 sup `verl/utils/pbd.py`，`_maybe_append_pbd_branch_rows`）先 clone 或复用；每次功能修改后做 code review；冒烟测试在 RTX Pro 6000 的 hold 上跑。
