# 师生分歧门控 + 教师自生成轨迹蒸馏：计划

**日期：** 2026-10-25
**状态：** v2（10-25）：检测器已定（prompt 末位 t=0 读出，零额外前向）；代码未实现，训练未开始。
**承接：** [TSW 首轮计划](tsw_initial_training_plan.md)（题级稳定性降权）。TSW r1 结果见第 1 节；预检代码 `OPD-Aha-sup/scripts/probe_disagree.py`（sup adba154），结果 `eval/probe_hidden/disagree_1025/`。

## 1. 动机

**TSW 首轮 r1 与 V0 打平**（gpt-oss-120b judge，pure-llm；step 60–130 八个 ckpt 平均）：

| 运行 | V* | ZoomBench | HR-4K | HR-8K |
| --- | --- | --- | --- | --- |
| V0 | 91.10 | 59.78 | 83.27 | 79.53 |
| PS（U 降权 0.5） | 90.44 | 59.23 | 82.41 | 78.75 |
| PH（U 置零） | 91.36 | 59.88 | 82.42 | 79.45 |
| RS（随机 25% 降权） | 90.18 | 59.41 | 83.11 | 79.22 |

- HR-Bench 跨实例计数题上，三个 TSW 臂都低于 V0，随机集合的 RS 也一样。所以 U 题型偏斜导致覆盖不足（假设 B）不成立。
- r2 仍在跑，按"每法两次"规则定论。

**题级降权没起作用。我们的解释是降权方向和问题所在的维度不对：**

1. **教师被学生前缀带偏（10-17 分叉探针）。** 教师自己生成时，只有 7–10% 会选学生的答案；在学生前缀下续写，这个比例升到 0.51–0.84。分叉点在 t≈0。V0 的教师只在学生轨迹上打分，所以在师生意见不同的题上，教师的真实意见基本传不给学生。
2. **分歧题恰恰是教师最该被听的题（10-25 预检，base 模型，各视图 8 样本，1024 token，T=1）。** 两视图多数答案不同（D=1）的题占 40.5%（有效 5073 题），在这些题上：
   - 教师准确率 0.638，学生 0.237，差 +0.40；一致的题（D=0）只差 +0.13。
   - D=1 内部：教师对、学生错占 81%，教师错、学生对占 10%。
   - 准确率都用样本 4..7 计算，与定义 D 用的样本 0..3 不重叠。
3. **TSW 的稳定性分数分不出分歧题（AUC 0.585）**，它和分歧是两个不同的轴。

**新假设：** 在师生分歧大的题上，把蒸馏轨迹从"学生生成、教师打分"换成"教师在自己视图下从头生成"。这样可以绕开前缀把教师带偏的问题，把教师的意见传给学生。

## 2. 分歧检测：prompt 末位 hidden 的 t=0 答案读出（10-25 用户确认）

### 2.1 信号定义

在**生成开始之前**，取 prompt 最后一个 token 位置、最后一层的 hidden，经模型自己的 LM head 得到"回答第一个 token"的分布；只保留本题选项字母（A–F 中本题出现的那几个，单 token）的概率，在选项内重新归一化：

- 学生视图（红框全图 + 提示 + 问题）→ p_S⁰
- 教师视图（裁剪图 + 问题）→ p_T⁰
- 门控统计量 g_i = TV(p_S⁰, p_T⁰) = ½ Σ_k |p_S⁰(k) − p_T⁰(k)|，按题计算，同一题的 n 条 rollout 共用

这不是"第一个生成 token 的 hidden"。它读的是 prefill 结束时、还没有采样任何 token 时模型的作答倾向：即使模型实际会先写 "The …" 再推理，这个倾向也照样读得出来。

例（四选一）：

| | A | B | C | D |
| --- | --- | --- | --- | --- |
| 学生 p_S⁰ | 0.10 | 0.70 | 0.10 | 0.10 |
| 教师 p_T⁰ | 0.05 | 0.10 | 0.05 | 0.80 |

g = 0.70，学生倾向 B、教师倾向 D，判为分歧题。

### 2.2 和 hidden 探针的关系：方法叙事

**方法叙事：** 答案倾向在生成前就已经写在 prompt 末位的 hidden 里。依据有两条：

- 10-20 探针：该位置的 hidden 预测多数答案的准确率 0.83，预测"多次采样是否一致"的 AUC 0.89；
- 10-17 分叉探针：分叉发生在 t≈0。

两个视图在这个位置的倾向不同，就标记了"教师意见会被学生前缀盖住"的题。读这个倾向最直接的方式，是模型自己的输出头（LM head）。

| 读法（同一 prompt 末位） | AUC（预测 D=1） | 需要训练？ |
| --- | --- | --- |
| **LM head 读出 TV(p_S⁰, p_T⁰)**（本方法门控） | **0.885**；与不相交样本 4..7 的 TV 的 ρ = 0.58 | 否 |
| L28 线性探针：学生 / 教师 / 拼接 | 0.635 / 0.675 / 0.695（打乱 0.49 / 0.51） | 是（标签来自 4 次采样，约 5k 题） |
| TSW 稳定性分数 1−p | 0.585 | — |

**hidden 探针的定位是机制分析，不作门控：**

- 逐层回答"分歧在哪一层开始可读"；
- 回答"只看学生、不跑教师时能否预知分歧"（学生视图 L28 探针 AUC 0.635，太弱，不作门控）。

**局限（如实记录）：**

- t=0 原始字母总质量的中位数约 0.45，近一半采样在第一个 token 就直接作答。所以这个读出与"采样多数答案不同"在机制上同源，更像是提前**测量**分歧，而不是预测推理过程会怎么分叉。
- 门控的价值已经在不相交样本上验证：t0-TV 前 25% 的题，教师−学生准确率差 +0.489，其余题 +0.146；这部分题里教师对、学生错 1144 题，教师错、学生对 78 题。
- 两个视图采样都用 vLLM seed=42，分歧比例偏低估。

### 2.3 训练时的计算：零额外前向

- **p_T⁰（离线一次）：** 打分用的教师是冻结的 base 模型，p_T⁰ 永远不变，直接复用预检已算好的 6241 题（`probe_hidden_answer.py --part hidden --view teacher`，full-vocab `log_softmax` 后取字母 token）。写进训练 parquet 的 `extra_info.dg_pT0`，6 维，未出现的选项为 0。
- **p_S⁰（在线，每步）：** 学生每步用 vLLM 生成 rollout 时，第一个生成位置的分布本来就算过了，只是现在只返回被采中 token 的 logprob（`vllm_async_server.py` 499/540 行，`logprobs=0`）。改动如下：
  1. 第一个生成位置额外返回 top-k logprobs（k=20），用 `raw_logprobs` 模式，即温度等处理之前的模型分布，与离线 HF 读出口径一致；
  2. 取出选项字母 token 的 logprob；不在 top-k 里的字母记概率 0，并记录"选项被 top-k 覆盖的比例"指标；
  3. 同一题 n 条 rollout 的 prefill 完全相同，取第一条即可。
- **口径核对（冒烟前置）：** 在 step 0（base 学生），vLLM 读出的 p_S⁰ 与预检里 HF 读出的 p_S⁰ 逐题比较，要求 TV 中位数 < 0.05 且 ρ(g_vLLM, g_HF) ≥ 0.9。不达标就改用备选：在 actor 计算 old_log_prob 的前向中读 prompt 末位的 full-vocab 分布（同样零额外前向，但要改 dp_actor 的返回值和行替换的顺序）。
- 不新增任何教师或学生的前向；门控只是把已有的数取出来。

## 3. 训练臂

底座、数据、超参与 TSW 首轮完全相同：off6k 6241 题，rollout_n=2，lr 2e-6，48 prompts/step，130 步，每 10 步存一次 ckpt，JSD α=0.5，top-100 加尾桶，seed 42。

| 臂 | 选题 | 被选中的题怎么处理 |
| --- | --- | --- |
| **DG**（分歧门控） | 每步 batch 内按 g_i 取最高 q=25% 的题 | 每题 n=2 条学生 rollout 中替换 1 条为教师轨迹，另 1 条保持学生 on-policy |
| **DR**（随机对照） | 每步 batch 内随机取同样比例 q 的题（不看 g，GT-free 固定 rng） | 同 DG |

- **教师轨迹从哪来：** 从冻结 base 教师在教师视图下离线生成的 8 条样本中取一条（`eval/probe_hidden/teacher_gen1024_1023/gen.json`，6241 题 × 8 条，1024 token）。
  - 只从答案等于教师 8 样本多数字母的那几条里随机选一条。这用的是教师自洽，不用 GT。
  - 没有唯一多数，或 8 条都没解析出答案时，这道题不替换。
  - 为避免和预检重叠导致乐观偏差，取样范围限定在样本 4..7（D 和 p_T⁰ 用的是 0..3 和 prompt 末位）。
- **损失：** 学生在学生视图 prompt 下前向教师轨迹的 token，冻结教师在裁剪图视图下给同样的 token 打分，用和 V0 相同的 JSD。这条轨迹本来就是教师自己生成的，所以教师在上面的分布不会被学生前缀带偏。
- **剂量对齐：** 用替换而不是新增，batch 大小和每步计算量都和 V0 相同。DG 和 DR 替换的题数相同，所以两臂的差异只来自"选了哪些题"。
- **监测（不屏蔽）：** 教师轨迹里的泄漏词（例如 "crop"、"zoomed"、"red bounding box"），统计其在替换行与非替换行中的出现率；推理期格式（缺 `<answer>` 的比例）和平均长度。
- **两臂各跑两次**（同配置 seed 42）。V0 不重训，用已有的 V0 r1（`off6kTSWv0n2`）作参照。

## 4. 判据（预先定下）

**主判据：** DG 两次运行的 step 60–130 平均，在 V\*、ZoomBench、HR-4K、HR-8K 中至少 3 项高于 DR，同时也高于 V0 r1。

**机制判据（同 ckpt，GT 只作诊断）：**
- 在训练集的高 g 题上，学生的多数答案与教师多数答案的一致率，DG 比 DR 提升得更多；
- g_i 的 batch 均值下降得更快；
- HR-Bench 跨实例计数题不低于 V0。

**否决条件：** 下面任一条出现，就判为风格污染而不是信息传递：
- 学生推理期的泄漏词率或格式漂移明显上升；
- 回答长度向教师轨迹的长度漂移，同时分数不升。

## 5. 风险与已知问题

- **离线教师轨迹是 off-policy 的。** 学生生成这种轨迹的概率可能很低。用 JSD（而不是 SFT）只对齐每个位置的分布，但学生的状态分布仍然和自己的 rollout 不一样。只替换 n=2 中的一条，是为了保留一半 on-policy 信号。
- **曾有类似的负结果。** PBD 在固定比例位置用教师续写，结果 ≈V0（V\* 92.15 / Zoom 59.41 / 4K 83.12 / 8K 79.25）。本计划和它有两点不同：从 t=0 开始用教师轨迹，而不是接在学生前缀后面续写；只用在分歧题上，而不是所有题。如果 DG 也 ≈ DR ≈ V0，说明"传递教师意见"这条路本身收益有限。
- **剂量可能偏小。** 25% 的题、每题替换 1/2 条，约等于 12.5% 的轨迹。如果第一轮看起来打平但趋势是正的，第二轮再考虑 q=50% 或 n 条全部替换；不加"A + 常数剂量"一类的对照。
- **教师视图泄漏。** 教师轨迹里会出现 "red bounding box"、对局部细节的描述等，等于把裁剪视角的说法带进学生视图。按规则只监测不屏蔽。

## 6. 设计决定与待定项

**已定（10-25 用户确认）：**
- 门控用 prompt 末位的 LM head t=0 读出 TV（第 2 节），零额外前向。
- hidden 探针只作机制分析，不作门控。

**按推荐默认执行（用户未另行指定前）：**
1. **教师轨迹来源：离线冻结 base 教师样本**（gen1024 样本 4..7 中取答案等于教师 8 样本多数字母的一条）。零额外生成成本，生成轨迹的就是打分的同一个冻结教师。
   - 另一选择是在线生成（PBD 做法），但那样 vLLM 装的是学生权重，教师就不是冻结 base 了，作为后续消融。
2. **门控比例 q = 25%**，与 TSW 首轮可比；每步在 batch 内按 g 排序取前 q。
3. **DR 对照**：同比例随机选题，用 GT-free 的固定 rng（seed 42 派生，按 step 变化）。

**实现流程（按既有规则）：**
- 参考代码：GATES 没有公开代码；分支行逻辑复用 sup 的 `verl/utils/pbd.py` 和 `_maybe_append_pbd_branch_rows`。
- 单测：TV 与重归一化、top-k 缺字母处理、门控选择（DG/DR 题数相等、同题共用）、离线轨迹选取（只取样本 4..7 中的教师多数答案、无多数则不替换）、替换后行张量与 V0 路径一致。
- 每次功能修改后做 code review（给出仓库路径）→ 回归测试 → 提交 sup。
- RTX Pro 6000 hold 上冒烟 2 步，检查：
  - 2.3 节的口径核对；
  - `dg/gate_frac`≈0.25 和 `dg/replaced_rows`；
  - g 的 batch 均值；
  - 选项被 top-k 覆盖的比例；
  - 替换行的泄漏词率（只监测）；
  - 每步时间 ≈ V0。
- 冒烟通过后，DG、DR 各跑两次，评测 V\* / ZoomBench / HR-4K / HR-8K，gpt-oss-120b judge 两种口径都算，主报 pure-llm。
