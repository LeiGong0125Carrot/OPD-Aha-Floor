# TSW：题级可靠性定位与追加探针计划

**日期：** 2026-10-24  
**状态：** 研究范围澄清与追加分析建议；未新增实验代码，未启动训练或资源申请。  
**依据：** [TSW 主计划](tsw_plan.md) 的 d5e9d31 版本，以及随后关于题级可靠性与学生 prefix 分析边界的讨论。

本文件补充主计划，不改写已有实验数据，不替换默认 OPD-Aha 配置。以下区分“已有结果”“方法假设”和“待做实验”；未核查的指标定义不得自行补全。

## 1. 研究定位：决定一道题值得多强的监督，而非修复每个教师 target

当前研究继承视觉特权 OPSD 的基本出发点：crop 条件下的同模型教师，在总体上具有优于全图学生的视觉作答能力。新增问题不是重新证明每个 prefix 上教师都更强，而是：

> 教师的题级可靠性存在差异，能否用无答案标签的一致性信号，对不同题目的蒸馏强度进行更合适的分配？

生成前 hidden 探针的角色是预测教师自身的答案分布稳定性。采样一致性是探针训练的伪标签，不是提供给学生的伪答案。教师稳定性与独立采样正确性的关系只通过 GT 诊断，不以 GT 训练探针或构造权重。

本轮保持：

- 学生照常生成 on-policy trajectories。
- 教师照常在相同 student prefixes 上给出原有 JSD 蒸馏 target。
- 同一道题的所有 rollout 共享一个题级权重。
- 只改变监督贡献，不修正教师答案、不选择同题哪条 trajectory 正确、不做 token-level 门控。

“稳定题全量蒸馏”的含义是保留原有监督过程、给予较强相对权重，不表示每一个教师 token 已被认证正确；归一化后部分权重可以大于 1。

## 2. 已有证据与仍待验证的假设

主计划记录了：

1. 在 1024-token 设置下，教师采样稳定性与独立采样正确性的关联明显强于学生侧。
2. 只用一致性标签训练的教师 prompt 末 token 线性探针，能够在图片分组交叉拟合中预测教师稳定性。
3. 教师探针分数与独立采样正确性、教师相对学生的作答优势存在分组趋势。

上述结果支持把分数作为题级可靠性代理。它们尚未证明“高分题单位训练预算的边际收益必然更大”，也未证明所有低分题都有害。

本轮核心算法假设是：

> 与等权蒸馏相比，减少低稳定性题目的相对监督贡献，能够改善最终学生性能或性能—成本权衡。

是否成立由匹配的训练对照回答，而不是要求在训练前证明所有 teacher/student prefix 的局部监督关系。

## 3. 三个概念必须分开

| 对象 | 当前状态 | 是否本轮必需 |
| --- | --- | --- |
| 教师生成前的题级分布稳定性 | 采样标签与 hidden probe 已有证据 | 是，分数来源 |
| 教师在特定 student prefix 上的条件监督可靠性 | 是另一种更细粒度分析 | 否，可选机制诊断 |
| 按分数加权后的实际学习收益 | 尚待训练对照 | 是，主验证 |

从 prompt hidden 出发并不意味着 prefix 完全不影响最终训练；它意味着本方法不需要将这种影响逐位置显式建模。若方法整体有效，可以先建立题级监督分配的经验贡献，而不声称已经定位或修复 prefix-induced errors。

术语上，teacher 对学生 prefix 的适应程度可以被研究，但不应简单称为“teacher 是否 off-policy”。此处 OPD 的 on-policy 指学生使用自身当前生成的 rollout 训练；离线获得题级分数不会把这种训练变成 off-policy。

## 4. 对此前追加探针建议的调整

**撤销“必须先证明生成前分数预测学生 prefix 上的教师正确性，才允许进行 TSW 训练”的要求。** 该要求把题级分配问题扩大成了局部纠错机制研究。

本轮不要求：

- 新生成大批 teacher-on-student-prefix 诊断数据；
- 标注第一个错误视觉关系；
- forced-readout/activation-patching 因果实验；
- hidden delta 注入、全层 hidden MSE；
- 继续扩大层扫描或不断提高 probe 容量。

主计划第 2.3 节中“追认式噪声梯度”的解释应被视为候选机制，而不是本轮必须证明的机制，亦不是解释性能提升的唯一原因。若保留此强机制主张用于论文，再补相应 prefix 实验。

## 5. 开训前需要完成的最小检查

这些是指标与对照有效性的检查，不是新增一轮机制探索。

### 5.1 统一标签和诊断定义

- 从现有脚本确认 det4：是四次均可解析且答案一致，还是至少三次可解析、可解析答案一致；不得按文字猜测代码。
- 明确无效标签、未解析和截断的处理，分别保存 valid_count、majority_count、correct_count。
- 区分逐采样正确率与题级正确事件；明确“过半”具体阈值。
- 对总体与四分位表核对样本集合、分母和指标定义；若不同，明确命名而非静默合并。
- 探针分、采样稳定性与 GT 之间的关联评估保持既定采样分离；GT 仅用于诊断。

### 5.2 保证 OOF 权重没有题目泄漏

- 训练集的 probe 权重来自未见过相应图片组的探针。
- 标准化、正则选择与任何概率校准都在训练 folds 内完成。
- 跨视图迁移使用相同图片分组，不能用某题学生 hidden 训练、再用同题教师 hidden 充当未见题测试。
- 为后续真正的新题训练最终全量 probe，与为当前训练集产生 OOF 权重区分开。

### 5.3 控制权重形状混杂

多数字母占比与 det4 的预测概率不是同一个量，直接使用二者会同时改变题目排序和权重强度。

两种备选设计，实施前固定其一：

1. **分布匹配设计：** 保留采样权重集合，按 probe 的 OOF 排序重新分配同一组权重。V0、TSW-sample、TSW-probe、TSW-shuf 四臂即可比较排序价值。
2. **原始概率设计：** 保留主计划中的 w=p，增加或另行安排 p-shuf，使 probe arm 具有自身权重分布匹配的随机对照。

第一种更适合控制首轮实验规模；这是本文件的建议，不是已实施的代码变更。不能仅用“p 方差更小”断言 s-shuf 对 p 加权是充分且保守的对照。

全局 token 加权归一保持平均损失权重为 1，不保证真实梯度范数或 loss 数值不变；不要重新按 micro-batch 归一。

## 6. 与研究目标直接相关的追加探针

### 6.1 优先但不阻塞训练：少量采样标签学习曲线

目的：验证 probe 是否能在只为部分题目进行多次教师采样后，推广到没有预采样的新题目。

- 固定图片分组的外层测试 folds。
- 在各外层训练池中使用 10%、20%、50%、100% 的稳定性标签。
- 固定候选主层，复用已有 hidden，不新增大范围层扫描。
- 报告 held-out 稳定性 AUC、校准/排序稳定性和各 fold 不确定性；GT 正确性指标只作诊断，不用于挑层或挑比例。
- 统计真实采样预算、prefill 成本和 probe 训练成本。已有数据上的子集实验是预算模拟，不声称此前采样成本已被节省。

这一实验服务“降低新题目可靠性估计成本”的扩展主张，不是 TSW-sample 是否值得训练的前置条件。

### 6.2 可选：同标签、不同视图的特征对照

统一预测目标为教师 det4，比较学生 prompt hidden 与教师 prompt hidden，以及简单元数据基线。使用同一套 grouped folds。

用途：判断教师视图是否提供额外预测价值，或分数主要反映共享题目特征。它不引入学生侧权重，也不要求必须证明一个视觉专属的稳定性方向。若论文不主张教师 hidden 必不可替代，这项不是必要条件。

### 6.3 可选：student-prefix 条件监督诊断

仅在需要解释训练负结果、分析学习阶段漂移，或主张“降低 prefix 追认导致的错误梯度”时实施。

不把该实验设为 Go/No-Go 前置条件；不因尚未做它而否定当前题级加权假设。若做，优先使用现成答案预测锚点，避免扩大为整个 trajectory 的逐位置纠错项目。

## 7. 主实验与成功标准

### 7.1 主要验证对象

最直接的问题是：在相同模型、教师冻结方式、off6k 视图、rollout 与优化预算下，题级加权是否优于等权 V0？

比较 V0、采样版、probe 版和对应的分布匹配随机权重。不同臂使用相同 seed 集、相同 checkpoint 选择规则与同一评测协议。仅复制运行目录而不改变训练 seed，不算独立 seed 复现。

### 7.2 Vision-OPD 与 OPD-Aha 的角色

- **匹配的等权 V0 / Vision-OPD-style baseline：** 检验题级权重本身是否带来收益。先区分本地冻结教师 baseline 与论文其他教师更新设置，不仅比较公开的峰值数字。
- **OPD-Aha：** 强性能参考，不是必须先复现其 prefix 纠错机制的研究目标。
- 若以更少在线教师计算达到接近 OPD-Aha 的性能，可作为性能—成本贡献；预计算、采样标签与 probe 成本必须单列，不能称为总成本为零。
- 接近/优于某基准的阈值与 checkpoint 规则在查看本轮测试结果前确定。两次运行范围重叠本身不是统计等价证明。

题级方法有效，不需要证明每条高权重轨迹均正确，也不需要证明低分组全部无价值；需要在有效对照下证明最终学生获得稳定改善或合理成本收益。

## 8. 执行顺序与停止规则

1. 完成第 5 节最小审计，冻结首轮权重/对照与评测口径。
2. 编写和 review TSW 训练代码；遵守现有登录节点与 GPU hold 规范，不由本文件自动启动任务。
3. 运行最小匹配训练对照。第 6.1 节可复用缓存并行分析，不阻塞主实验。
4. 依据训练结果决定是否补第 6.2/6.3 节；不无限追加探针替代训练验证。

**主线：特权教师的题级稳定性具有可靠性排序意义 → 生成前表示可低成本预测该信号 → 用于题级监督分配 → 通过最终训练性能验证。**

本文件未修改已有主计划的原始数字、训练配置或代码；未申请 GPU、未创建监控任务。
