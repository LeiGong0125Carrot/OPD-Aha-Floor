# 14｜完整精确数值例子

**用途：** 将所有模块串成一个可重算的例子。所有数字均为合成教学数据，不是模型预测或实验结果。
**代码：** `python -m reference.generate_example`；完整机器可读数据见 [JSON](examples/worked_example.json)。

## 1. 输入与约定

两条已采样response各有6个有效位置；这里只构造局部cost数组。前3步累计量相同，不要求实际文本prefix相同，也不是训练时额外枚举两个未来。

```text
rollout 1: cost = [.20, .30, .30, .10, .30, .20]
rollout 2: cost = [.20, .30, .30, .10, .02, .00]
```

所有位置mask=True。示例使用probability-gap、Phi(H)=2H-log(1+H)、gamma=1；PPO epsilon=.20、anchor lambda=.10只是教学配置。

当前重点位置是代码index=3，即数学公式的第4个response位置；两条在这里H=.80。

## 3. 当前第4个位置的风险计算

第一条原始后缀代价=.60：

$$R_1^\Phi=\Phi(1.40)-\Phi(.80)=1.20-\log(2.40/1.80).$$

第二条原始后缀代价=.12：

$$R_2^\Phi=\Phi(.92)-\Phi(.80)=.24-\log(1.92/1.80).$$

精确到12位小数：

```text
R1 = 0.912317927548
R2 = 0.175461478862
A1 = R2-R1 = -0.736856448686
A2 = R1-R2 = 0.736856448686
```

这说明negative-only代价仍能产生正向advantage；正A表示相对低风险，不是有GT证明答案正确。

## 4. 更新第一条当前位置

采样时old probability=.70，更新中new probability=.63，因此ratio=.90。A取上表未舍入值；epsilon=.20时不触发clipping。

```text
ratio = 0.900000000000
policy loss = 0.663170803817
```

Teacher real三token完整分布为[.70,.20,.10]，student为[.63,.27,.10]。null sampled-token probability可取.80，因此当前位置c=.10，与输入数组一致。未规定其余位置的完整词表分布；本例不伪装成完整VLM生成记录。

```text
JSD anchor = 0.003537583631
total loss (lambda=.1) = 0.663524562180
```

如果将A先四舍五入为-.737再算，policy loss=.6633，而不是未舍入的.663170803817。测试必须固定使用未舍入值或明确单独测试教学舍入例子。

## 6. 这个例子没有验证什么

没有验证teacher的视觉信号是否可靠、gamma/epsilon/lambda是否适合spatial任务、Phi是否提升准确率、PPO是否避免循环、anchor是否保护能力。它只验证各模块计算能一致地接起来。
