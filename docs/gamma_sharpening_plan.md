# 目标锐度实验（γ-sharpening）—— 实施计划

**一句话**：OPD-Aha 的蒸馏目标有 98% 质量压在单个 token 上；本实验检验**剩下 2% 的软分布
到底有没有用**。这是目前唯一一个能改变研究方向的问题。

---

## 一、动机：一个已测到的事实

昨夜为 tanh 臂加的诊断指标 `self_distillation/target_max_prob`（目标分布最大概率，51 步均值）：

| 臂 | target_max_prob（51 步均值） |
|---|---|
| **纯 A（rr2，γ=1，无任何门）** | **0.9264** ← 这才是 A 的数 |
| floorn2（开 floor α=0.1） | 0.9824 |
| tanhn2 / tanhn2r2（开 tanh τ=0.5） | 0.9766 / 0.9784 |

**一处已修正的误读**：本计划初稿把 0.9824 当成"A 的目标构造"，但那是 **floorn2** 的数（开了
floor 门）。纯 A 的真实值是 **0.9264**（rr2，它是 γ=1 且跑在该指标加入之后）。
所以软质量是 **约 7%**，不是 2% —— 问题仍然成立，而且 7% 比 2% 更值得问。

另外，训练期的 `target_max_prob` 跨臂比较**不干净**：它同时受 student 自身轨迹影响
（support 是 student 的 top-k，student 越自信目标越尖）。要测"变换本身"的效果，须在
**同一批张量**上比较——用探针 dump 喂生产函数实测（`probing/check_target_sharpness.py`）：

| 同一批真实张量上 | target_max_prob | 熵 |
|---|---|---|
| A（γ=1） | 0.7949 | 0.631 |
| floor α=0.1 | 0.7916 | 0.651 |
| tanh τ=0.5 | 0.7845 | 0.669 |
| **γ=50** | **0.9930** | **0.011** |

口径已交叉验证：同一批张量上 `target_tv=0.333 / raw_jsd=0.199`，与训练日志的 ≈0.31/≈0.19 一致。
可见 **floor 与 tanh 对锐度的影响都 <0.01，而 γ=50 是唯一真正改变锐度的旋钮**——这正是本实验
需要的单变量。

这解释了一个反复出现的现象：本仓库 8 个"改目标构造"的臂峰值全部 ≤ 50.37，而 A 的四次
有三次 ≥ 51.11。**我们可能一直在调一个实际不起作用的自由度——软分布的形状。**

## 二、实验设计

### 机制

在目标构造的**最后一步**（tilt / floor / sup / ST 全部算完之后）加一个锐度旋钮：

```
log q_γ = log_softmax( γ · log q )
```

| γ | 含义 |
|---|---|
| **1.0** | 恒等 —— 必须与 A 臂 **bit-identical**（回归保护） |
| **→ 大**（实测用 50） | 硬标签。q_max=0.98 时 `0.98^50 / 0.01^50 ≈ 10^85` ⇒ 数值上就是 onehot(argmax q) |
| **< 1**（如 0.5） | 更软 —— 反方向，放大那 2% |

一个旋钮覆盖两个方向，实现成本与只做硬标签相同。

### 为什么加在最后

- 与已有的 floor / sup / ST / tanh **全部可组合**（它们都在更早的位置改 u 或改 q）
- γ=1 时是严格恒等，所以 A 臂的回归风险为零
- 语义干净：它只改"目标有多尖"，不改"目标偏向谁"

### 数值安全性（已推导）

JSD（α=0.5，`m = 0.5p_S + 0.5q`）在 q 为 one-hot 时：
- `KL(q‖m) = log(1/(0.5·p_S,i + 0.5)) ≤ log 2`，有界
- `KL(p_S‖m)`：v≠i 处 `m_v = 0.5p_S,v` ⇒ 项 `= p_S,v·log2`；v=i 处亦有限

所以 **loss 上界 log2 ≈ 0.693，无 log(0)、无爆炸**。`log_softmax` 自带减最大值，
γ=50 时 `γ·log q` 低至 −2500 也不会下溢。

### 尾桶必须排除（code-review 抓到，且定量上很重要）

目标的最后一列是**尾桶**——student top-k 之外的聚合质量，是截断产物而非 token。
若把 γ 也作用在它上面：

- γ<1 时会把它抬高几个数量级（实测错版 tail 0.120 vs 正确 0.100），等于在告诉 student
  「把质量移到 top-k 之外」，而这恰恰不是本实验要测的量；
- γ 很大时，凡是尾桶恰为 argmax 的位置会变成「硬标签：不在 top-100 里」。

**真实数据上这不是小概率**：探针张量实测尾桶质量均值 **0.079**（中位数仅 1e-4，p90 0.039
——偶尔很大），而 **argmax 落在尾桶的比例是 7.85%**。也就是说不修的话，约 8% 的 token 会被
下成「不在 top-100」的硬标签。

已修：γ **只作用于显式列**，并把它们重新归一化到**原有的显式总质量**，尾桶的 log-prob 原样保留。
于是有硬不变式 `q_max ≤ 1 − tail`（单测钉住），真实数据下 γ=50 的 `q_max` 上界约 **0.921**。

### 一个已知性质：γ 压不硬「近似并列」的位置

任何**有限** γ 都无法让近似并列的两个 token 变成 one-hot —— 若 top-2 在 γ=1 时比值为
`1+ε`，γ 次幂后仍是 `(1+ε)^γ`，ε 很小时依然接近并列。单测在合成 fixture 上量到了这一点
（那里 `q_max` 仅 0.4686，最软的位置 γ=50 后仍是 0.9974）。

但在**真实训练的量级**上这不成问题：实测 `q_max = 0.9824`，次高至多 0.0176，
首/次比值 `(0.9824/0.0176)^50 ≈ 2×10^87`，数值上就是硬标签
（单测用一个"真实锐度"的 fixture 验证了 γ=50 → `q_max > 0.9999`、熵 ~1e-7）。

**解读上的含义**：γ=50 会**保留那些真正有歧义位置的软质量**。所以如果结果 ≈ A，
严格的表述是「除近似并列位置外，软分布无用」，而不是「软分布完全无用」。
`target_entropy` 指标能直接量出这部分残留有多大 —— 若训练中它显著 >0，说明近似并列位置
不少，那时才需要补一个真正的 one-hot 变体（`scatter` argmax）来排除这一解释。

## 三、预登记判据（只看峰值，×2 规则）

参照锚：**A(opd-aha)+pair 在本仓库的四次观测 = 49.88 / 51.11 / 51.11 / 51.60**。
判"有增益"要求两次跑的峰值**都** > 51.60；判"有害"要求两次都 < 48.3。

| γ=50（硬标签）的结果 | 结论 | 行动 |
|---|---|---|
| 峰值 ∈ [49.88, 51.60] | **软分布无用**。OPD-Aha ≡「选特权视图偏好的 token 做 CE」 | 方法可大幅简化；8 个改造臂的失败得到统一解释；论文叙事要改 |
| 两次都 < 48.3 | **那 2% 就是视觉信息的载体** | 转向 γ<1（放大软部分），而不是继续重塑形状 |
| 两次都 > 51.60 | 目标过软反而有害（未预期） | 扫 γ > 1 |

### 一个必须同时读的混杂

q 变 one-hot 后 JSD 有界（≤log2），**梯度幅度可能比软目标小** —— 若硬标签臂变差，
可能是有效步长变小而非软质量重要。所以必须同时看：

- `self_distillation/raw_jsd_token_mean`（A 臂约 0.19）
- `actor/grad_norm`（A 臂前几步 3–7）

若硬标签臂的 grad_norm 系统性低 2 倍以上，则需补一个 **lr 匹配**的变体才能判读。
这条写在前面，避免事后找理由。

## 四、新增诊断指标

| 指标 | 用途 |
|---|---|
| `self_distillation/target_max_prob`（已有） | 确认 γ 真的起作用了（γ=50 应 →1.0；γ=0.5 应明显 <0.98） |
| `self_distillation/target_entropy`（新增） | 比 max_prob 更全面地刻画锐度；γ=50 应 →0 |

两者都无条件上报，所以**所有后续臂都能横向对照**，不用再回头补跑。

## 五、跑法

| 项 | 值 | 理由 |
|---|---|---|
| 算法 | A 臂（完整 tilt）+ γ 门 | 单变量 |
| 数据 | `train_6karmA_pair.parquet` | 标准训练集 |
| 并行配置 | **2卡 / SP=2** | **与 ahaAn2 / rr2 逐项匹配**，对照最干净 |
| n / lr / batch / 步数 / seed | 2 / 2e-6 / 48 / 51 / 42 | 同 A |
| 重复 | **×2**（`gam50` 与 `gam50r2`） | 用户规则 |
| 成本 | 2卡/SP2 实测 ~6.8 min/步 ⇒ **约 5.8h/次** | rr2 实测 41 步用 4:41 |

排在 hold 20513321（2卡，余 28h）上，`ahaAn8sp1` 评测完（约 23:15）之后接。
两次训练 + 两次评测约 **15.6h**，放得下。

**建议同时砍掉** `ahaAn8sp1r2`（原排在 3 卡 hold 上，12h）—— 它是为一个已关闭体制
（n8 无优势且贵 4 倍）补 ×2，性价比远低于本实验。

## 七、不做什么

- 不动 A 臂的任何默认行为（γ=1 必须 bit-identical，单测钉住）
- 不与 ST 同时开（ST 自己替换整个目标，语义重叠）——校验拦截
- 不在本实验里扫 γ；先用 γ=50 拿到二分答案，再决定要不要扫
