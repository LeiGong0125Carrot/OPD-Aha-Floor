**动机**：aha-opd 的 `u_t(v)` 逐位置独立计算、loss 按 `token-mean` 聚合，管线里没有任何地方
能看到"视觉证据沿轨迹的趋势"。目标是找出轨迹级的有效信息，用于 rollout-level reweight。

**数据**：736 条 rollout（8 个 checkpoint：base / ahaAn8 step30,40,50 / supn8 step10,25,40,50），
全部复用 rollout-disagreement 探针的 dump，**零 GPU**。探针 `probing/probe_traj_structure.py`、

## 一、结论：这条路不值得投训练资源

三个候选维度全部不可用，而且第三个的否定理由是**理论性的**（不是数据不足）：

| 维度 | 测量 | 结论 |
|---|---|---|
| 两通道构成 | `corr(frac_N, 总强度) = −0.777`、CV=0.15（判据边界） | **不独立于强度** |
| 时序持续性 | `ρ(1)=0.151`、`ρ(5)=0.075`（67% 轨迹 ρ(1)>0.1） | **弱**（仅 2.3% 方差可由前一步解释） |
| 位置结构 | 96-98% 轨迹单调递减，但前 20% 位置只携带 26.9% 信号（富集 1.34×） | **真实但幅度温和** |

## 二、位置结构的完整刻画（这部分是可靠的正面结果）

沿**语义锚点**（答案声明位）分段，n=359（T≥25，窗口 ±5）：

| 段 | N 均值 | 相对全轨迹 |
|---|---|---|
| 轨迹最前 5 token | **0.0629** | 1.35× |
| 中段（开头→声明前） | 0.0511 | 1.10× |
| 答案声明前 5 | 0.0315 | 0.68× |
| **答案声明后 5** | **0.0092** | **0.20×** |

形状是**单调递减 + 声明后断崖**：`0.063 → 0.051 → 0.032 → 0.009`，
**最前/声明后 = 6.81×**，声明前/后 = 3.41×。

窗口稳健性（effect 随窗口缩小而增强，说明断崖是尖锐的）：

| 窗口 | n | 声明前/后 |
|---|---|---|
| ±15 | 35 | 2.12× |
| ±8 | 176 | 2.51× |
| ±5 | 359 | **3.41×** |

**三个语义锚点里只有一个有效**：

| 锚点 | 效应（前/后） | n | 说明 |
|---|---|---|---|
| 答案声明位 | **3.41×** | 359 | 有效 |
| GT 选项文本首现 | 0.90× | 536 | 无效 —— 选项词（"black"/"Bajaj"）在描述段就出现，不构成判断时刻 |
| 反思词首现 | 1.26× | 34 | 无效且样本少 —— 选择题短答里的"反思"不是论文（数学长 CoT）场景 |

与 qcontrast 旧探针的独立吻合：那个测 GT **对象名**提及前 1.97 vs 后 0.59 = **3.34×**。
两个不同设计、不同锚点、不同数据集，同一量级。**但正确的读法是"语义事件之后信号衰减"，
不是"事件之前信号增强"**（见下一节的纠正）。

## 三、决定性的理论认识：loss 已经自动加权了

这一点改变了整个"加权"命题的前提，此前没想清楚：

> `token-mean` 不是"每个 token 的**梯度贡献**相等"，而是"每个 token 的 **loss 值**等权平均"。
> 而 loss 就是 `JSD(q_t, p_S,t)` —— **视觉信号强的位置，q 偏离 p_S 更多，loss 自然更大、
> 梯度贡献自然更大**。视觉敏感的 token 已经自动获得了与其信号强度成正比的权重。

所以位置加权想做的事，**大部分已经由 loss 自己完成了**。这解释了为什么位置富集只有 1.3×
——不是"信号与权重严重错配"，而是**加权基本已经对了**。

剩下唯一明确的浪费：答案声明后的 token（约占轨迹 9%，信号 0.20× 均值）loss 接近 0，
对分子贡献 ~0 但对 `token-mean` 的**分母贡献 1** → 整体 loss 被稀释约 9%（等效于学习率
低 9%）。可以精确修掉（声明后截断 loss，零超参），但量级就是 9%，在 TB 的 ±1.5-2 点
噪声带里读不出来。

另外记录一个此前未被审视的事实：**rollout 长度 T 从 4 到 1024**（p10=4、p90=230、均值 132），
`token-mean` 下最长/最短 rollout 的梯度权重比 **512×**，纯由长度决定。

## 四、四条方法论教训（都是本轮自己踩的）

1. **`P − N = KL(p⁺‖p⁰) ≥ 0` 是恒等式**。第一版用 `corr(P,N)=0.784` 判"两通道不可分离"，
   但两者被该恒等式绑定（共同因子=视觉证据总强度），那是**循环论证**；且"100% 轨迹抬升主导"
   是 KL 非负性的平凡推论，不是数据性质。修正做法：先除掉总强度，用构成量
   `frac_N = N/(P+N)` 或 `P/N`。修正后结论仍是判负，但论证干净。
2. **峰值位置 ≠ 集中度**。我从 `peak_pos_N` 中位数 0.136（峰值在前 14%）推出"前 40 个 token
   携带强信号、后 250 个几乎没有 → 稀释 6×"，实测富集只有 **1.3×**——分布是**缓慢线性递减**，
   不是断崖。这个错误一度支撑了一个很强的（错的）结论："信号错配可能解释为什么所有目标构造
   改动都在 ±1 点内"。
3. **别把写死的提示文字当结论**。脚本里预写了"corr(frac_N, 强度) 接近 0 ⇒ 两个独立维度"，
   实测 −0.777 直接证伪了那句话。预登记判据要写成条件分支，不能写成断言。
4. **语义锚点的效应必须分解来源**。"声明前/后 = 3.41×" 有两种读法："前高"或"后低"。
   分段后是**后低**（声明前 0.68× 全均值、声明后 0.20×）。两者的行动含义完全相反：
   前者会指向"在决策点加强干预"（错误建议），后者只说明"后段无信号可学"。

## 五、由此更新的"活/死"地图

**已判死**：C-temporal、Q-contrast、setshift、ST（守恒转移+硬门）、TGNVMT 轨迹门控、
rollout-disagreement 假设、**轨迹级 reweight（本文）**。

**已验证持平不塌**：SAD（λ=0，同分但改风格 → 风格由 anchor 承载）、
supn8（u⁻ tilt，同分不改风格，且只用 1/4 剂量 → 正半边的指数重排冗余）。

**仍活且未测**（按先验排序）：

1. **`tanh` 有界化**（TGNVMT 文档里与门控可分离的部件）：把 `e^{β·u}` 换成有界函数。
   解决一个已量化的真实问题 —— 六 token 算例上 β=4 时单个 `u=+1.92` 的 token 独吞
   **99.76%** 的目标质量（TV=0.83），即 A 臂的目标在许多位置实际是被一个极端 u 决定的
   near-one-hot。它**不动**已验证的有效成分（负向抑制），只改抑制强度在 token 间的分配；
   与 supn8 正交可叠加；而且方向是**去极端 = 更弥散**，符合 ST 教给我们的"抑制需弥散"定律。
2. **Layer-3 软权重守恒转移**（去掉 ST 的硬 donor 门，用 `1−e^{β·min(u,0)}` 覆盖所有 u<0）。
   先验较差：ST 的末端下滑与翻转不对称可能指向"守恒转移本身"而非只是硬门。

**在跑/排队**：an8lr8（lr-scaling）、supn2、ahaAn2rr1（复现性）、flAn2（floor 非 pair）、
floorn2（floor pair）。
