# tanh 有界化臂 (bounded tilt) —— 算法参考

实现 commit 见 git log；门控 `self_distillation.counterfactual_tanh_scale`（0 = 关闭，
关闭时与 A 臂**逐位相同**）。单测 `scripts/test_tanh.py`（7 组，纯 CPU，全绿）。

---

## 一、它改的是哪一行

OPD-Aha 的目标构造（A 臂）：

```
u(v)   = log p⁺(v) − log p⁰(v)          视觉证据对 token v 的对数似然比
q(v)   ∝ p⁺(v) · exp(β · u(v))          β = 4
```

本臂只把 `u` 换成它的有界版本，其余一字不动：

```
ũ(v)   = τ · tanh( u(v) / τ )
q(v)   ∝ p⁺(v) · exp(β · ũ(v))
```

于是 tilt 因子 `exp(β·ũ)` 被关进 `[e^{−βτ}, e^{+βτ}]`。
**τ = 0.5、β = 4 → 区间 [0.135, 7.39]**（原版无上界）。

两个极限（单测 [1] 已验证）：`τ→0` 时 `q → p⁺`（退化为不蒸馏视觉对比）；
`τ→∞` 时 `q →` 原始 A 臂。所以 τ 是一个**连续插值旋钮**，不是新机制。

---

## 二、为什么值得试：一个已量化的病理

`exp(4u)` 对 u 是指数放大，目标因此**由最大的那个 u 独裁**。六 token 算例
（docs/trajectory_measurements_verdict.md §五.1）：单个 `u = +1.92` 的 token
拿走目标质量的 **99.76%**，`TV(q, p⁺) = 0.83` —— 目标实际上是个 near-one-hot，
其余 token 携带的视觉对比信息被指数压成了零。

tanh 的作用**不是削弱 tilt，而是重新分配它**：

| u 的区间 | τ·tanh(u/τ) 的行为 | 后果 |
|---|---|---|
| 小 `\|u\| ≲ 0.1` | ≈ u（偏差 <1.5%，单测 [3]） | 已验证有效的那部分信号**原样保留** |
| 中 | 亚线性压缩 | 温和收敛 |
| 大 `\|u\| ≫ τ` | 饱和到 ±τ | 极端 token 不再独吞 |

单测 [5] 在同一个六 token 算例上直接验证：`q_max` 从 **0.9986 → 0.8569**。

方向上，这与 ST 臂教给我们的定律一致：**抑制需要弥散**。tanh 做的正是"去极端 = 更弥散"。

## 三、可组合性（为什么能和已有臂叠加）

`tanh` 是**奇函数且非降**，所以它**保号、保序**。下游两个门都只看 u 的符号：

- floor 的掩码是 `valley & (u < 0)` —— valley 只依赖 `p⁺`，`u < 0` 保号不变；
- sup 的 `clamp(u, max=0)` —— 与奇函数可交换：`τ·tanh(min(u,0)/τ) = min(τ·tanh(u/τ), 0)`。

单测 [4][7] 逐条验证了这三点，并确认打开 tanh 后 `floor_clamped_frac` 与
`sup_frac_u_pos` **一位不变**（1e-12 内）。因此 `tanh × {A, floor, sup}` 三种组合都合法，
且 tanh 是一个**正交旋钮**。

与 **ST 互斥**：ST 整段替换了 tilt（改成守恒转移），根本没有 `exp(β·u)` 可以去界。
dataclass 校验会直接拦截（单测 [7]）。

## 四、一条必须知道的代价

float32 下 `tanh(x)` 对 `|x| ≳ 9` 返回**恰好** ±1。所以 `|u| ≳ 9τ`（τ=0.5 时约 4.5）
的所有 token 拿到**完全相同**的 tilt —— 极端之间的**序被抹平**。

这是有界化的定义性代价而非 bug，但它意味着 **τ 不能取太小**：τ 越小，被抹平的区间越大。
单测 [4] 把这条显式钉住（`u=5` 与 `u=10` 都映到 0.5）。

诊断指标 `self_distillation/tanh_compressed_frac`（`|u| > 2τ` 的 token 占比）就是用来
在真实训练里读这个代价的 —— 若它很高（>0.3），说明 τ 选小了。

---

## 五、新增的两个诊断指标

| 指标 | 定义 | 读法 |
|---|---|---|
| `self_distillation/tanh_compressed_frac` | `\|u\| > 2τ` 的 token 占比 | 读作"进入非线性区的比例"，**不是"顶到界"** —— tanh(2)=0.964，序仍保留；序被抹平要到 `\|u\|≳9τ`。过高 ⇒ τ 偏小 |
| `self_distillation/target_max_prob` | `max_v q(v)` 的 token 均值 | **所有 counterfactual 臂都上报**，可直接对照 A 臂看"独裁"被削弱了多少 |

`target_max_prob` 是本臂的**机制读数**：如果它没降，说明 tanh 没起作用；
如果它降了但分数没动，说明"目标过度集中"根本不是瓶颈 —— 这是一个能**自我证伪**的设计。

## 六、预登记判据

主战场 TreeBench，**只看峰值**（用户口径）。参照锚点（judge 口径，同仓库同数据同 51 步）：

| 参照 | TB 峰 | V* 峰 |
|---|---|---|
| ahaAn2 (A + pair + n2) | 49.88 | 94.76 |
| ahaAn2rr1 (同上，复现) | 51.11 | 93.19 |
| an8lr8 (A + pair + n8 + lr8) | 51.60 | 91.62 |

本季波动上界：**峰差 ≤ 1.6**（rr1 给出，且含并行配置混杂，故偏保守）。

| tanh 的 TB 峰 | 判读 |
|---|---|
| > 53.2（= 51.60 + 1.6） | **真实增益** —— 目标过度集中确是瓶颈，值得继续加码（扫 τ） |
| 50.0 – 53.2 | 与 A 族持平 —— 病理真实但不是瓶颈；同 supn8 归入"持平不塌"类 |
| < 48.3（= 49.88 − 1.6） | 有害 —— 极端 u 的独裁**是**有效成分，有界化伤到了它 |

无论哪一档，`target_max_prob` 的前后对比都能把"机制是否发生"与"机制是否有用"分开 ——
这是前几个判死臂缺的东西（它们只有分数，没有机制读数）。

**运行规则**：按 ×2 规则跑两次，配置逐项锁定（`ULYSSES_SP` 已参数化并在启动时回显）。
