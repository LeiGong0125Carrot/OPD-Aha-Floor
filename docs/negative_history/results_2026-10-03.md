## 2. 结论

### 2.1 C 只是剂量效应（negative_history C 线收官）

supb63 用常数 β=6.3 匹配 C 的平均 β_t（6.31 / 6.19）。TB 池化 46.96 vs C 47.53，V\* 90.05 vs 90.58，同带。
**C 的累积历史模块在剂量之外没有贡献**，与 `nhC_r1_casestudy.md` 的"历史饱和 → 退化为剂量"一致。

### 2.2 Ahm：V\* 持平 A，TB 不达标

- **TB**：两次峰值 48.64 / 49.88 均 < 50.5；池化比 A 低约 1.3。
- **V\***：池化 92.93 与 A 92.84 持平；第 1 次峰值 94.24 落在 A 区间内。
- 与 sup 家族对比：sup 家族 V\* 低 2–4 点，Ahm 不掉。**把历史调节放到 A 底座上避开了 sup 底座的代价，但只加强抑制换不来 TB。**

### 2.3 Ahm 机制读数（51 步均值）

| | Ahm | Ahmr2 |
|---|---|---|
| s 均值 | 0.386 | 0.399 |
| β_t 均值 | 5.54 | 5.60 |
| 额外剂量 Δβ = β_t − β | ≈ 1.54 | ≈ 1.60 |
| c > 0 比例 | 0.41 | 0.42 |

第 1 步 Δβ ≈ 2.0，训练中降到约 1.45–1.6：学生学好后 realized 视觉冲突 c 变小，历史门随之关小。

## 3. Ahf ×2（`aha_history_future_residual_design.md` v0.1）：训练完成，评测中

实现：`counterfactual_hist_mode=hf`（OPD-Aha-Floor:sup `02fa4c2`），Δβ_t = β·h_t·f_t·η_t 只作用于负半边。

| 51 步均值 | Ahf | Ahfr2 |
|---|---|---|
| s 均值 → Δβ | 0.096 → **0.39** | 0.104 → **0.42** |
| h / f 均值 | 0.39 / 0.22 | 0.41 / 0.23 |
| η（正常结束行比例） | 0.989 | 0.986 |
| s 的 rollout 间方差 / 轨迹内方差 | 0.0077 / 0.0047 | 0.0075 / 0.0050 |

- Δβ 只有 Ahm 的约 1/4；f 均值小于 h，因为回答后半段冲突更少。
- 截断率约 1.2%，确认"有效长度 == padding 宽度"的截断判据有效。
- **h·f 是"按 rollout 分剂量"还是"轨迹内时间调节"**：rollout 间方差约占 60%，轨迹内约 40%。设计文档 §8.5 / §12.3 担心的常数化只部分成立。
- TB 规则分（judge 待出）：Ahfr2 step30 45.93、step40 47.41。
