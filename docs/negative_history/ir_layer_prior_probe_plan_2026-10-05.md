# 探针计划：哪些层像"语言先验"，能否用其读出替代 visual null（2026-10-05）

> 状态：计划（用户 10-05 11:10 提议，待实施）。前置：`teacher_internal_residual_reconstruction_plan.md`（路线一 IR 设计）、`ir_results_2026-10-05.md`（IRf λ=1 / IRfl4 λ=4 结果）、`null_free_line_summary_2026-10-04.md`（S/St/S2 为何失败）。
> 目标不变：去掉 null 前向、只用一次冻结特权教师前向，达到接近 A 的效果（TB > 50，V\* 92–93）。

## 1. 动机

### 1.1 A 的纠正方向是什么
OPD-Aha（臂 A）的目标 q ∝ p⁺ · exp(β·u)，u = log p⁺ − log p⁰。p⁺ 是冻结教师看 [全图, crop] 的分布，p⁰ 是同一教师看 [全图, 均值色块] 的分布。u 的本质是**"减掉一个看不到 crop 的分布"**：它把教师分布里不依赖 crop 的部分（语言先验 + 全图能看出的部分）消掉，只留下 crop 带来的增量。S 线的结论（§4.1）是这个"减法"不能用学生分布替代，V\* 的 +5 全部来自它。

### 1.2 路线一 IR 到目前为止在做什么、为什么失败
IR 把纠正方向换成"同一次前向里某一段 block 的贡献" r = τ⁻¹ W_out D_t (h^b − h^a)，q ∝ p⁺·exp(λr)，隐含假设是"中层 [12,20) 的贡献 ≈ crop 增量"。结果：

| 臂 | 目标 TV(q, p⁺) | TB 峰 | V\* 峰 | 现象 |
|---|---|---|---|---|
| IRf λ=1 | 0.09 | 47.65 | 87.43 | ≈ V0，目标几乎就是 p⁺ |
| IRfl4 λ=4 | 0.27（= A 的量级） | 46.67 | 85.86 | 双基准都降；回答变长、缺 `<answer>` 12–15% |
| A | ≈0.27 | 49.9–51.6 | 91.6–94.8 | — |

同样大小的目标偏移，A 换来 +5 V\*，IR 换来 −2。说明 [12,20) 的贡献方向与 crop 增量**不等价**：放大它放大的是长度/风格，不是对 crop 证据的偏好。继续盲扫区间（[8,24)、[20,28)、[24,32)）每臂要 4.5 h 训练+评测，而且即使某个区间碰巧更好，也不知道为什么。

### 1.3 用户的提议
与其放大某一段的贡献，不如反过来问：**网络内部哪一部分的读出最像 p⁰（看不到 crop 的分布 / 语言先验）？** 若存在某层 ℓ 或某个 block 集合 S，使其读出 p̂ ≈ p⁰，就可以用 û = log p⁺ − log p̂ 代替 u，目标 q ∝ p⁺·exp(β·û)，形式上与 A 完全一致，但只要一次前向。这个问题可以**离线直接量**，不需要训练。

### 1.4 为什么这个探针有结论力（无论结果如何）
- 若某个内部读出与 p⁰ 足够接近（指标见 §3），就得到一个有依据的 null 替代，直接进入训练验证。
- 若所有层、所有 block 子集的读出都离 p⁰ 很远，说明 null 的信息是**输入侧注意力重算**出来的（去掉 crop 后，全图 token 的注意力分布也变了），内部任何线性读出都复现不了。这会把"单次前向线性读出"整条线干净地关掉，比扫四个区间更有结论力。

## 2. 探针设计

### 2.1 数据与回答
- 训练集 `train_6karmA_pair.parquet` 抽 400 题（seed 42，固定）。
- 回答：base 模型（Qwen3.5-4B 初始权重 = 第 0 步学生 = 冻结教师）看全图贪心生成，max 1024 token。第 0 步学生与教师同分布，正是 A 定义 u 的 on-policy 起点。
- 评分位置：回答的每个 token 位置 t（预测 y_t 的位置 P+t−1），与训练完全一致。

### 2.2 三次教师前向（都是冻结教师，HF eager，bf16，hook 只读）
| 前向 | 输入 | 读出 |
|---|---|---|
| real | [全图, crop] + 问题 + 回答 | 最终 logits z⁺；每个 block 边界的残差 h^0 … h^32；最终 norm 的 D_t |
| null | [全图, 均值色块] + 问题 + 回答（与 `_build_null_view` / `null_scope=last` 同构） | z⁰ → p⁰，真 u = log p⁺ − log p⁰ |
| text | 只有问题 + 回答（无图） | z_text → p_text（纯语言先验参照） |

real 前向里派生两类候选：
- **logit-lens**：p_ℓ = softmax(τ⁻¹ W_out · D_t · h^ℓ)，ℓ = 0…32（用最终 norm 的 D_t，与 IR 同口径；另算一版用该层自身 norm 的缩放，看是否敏感）。
- **block 贡献**：r_j = τ⁻¹ W_out D_t (h^{j+1} − h^j)，j = 0…31；任意区间 [a,b) 的贡献 = Σ r_j。

### 2.3 支持集与统计口径
全部指标在**学生 top-100 + tail** 支持集上算（与训练损失同口径），按 token 加权，另报"答案位置"（回答中首个选项字母 / `<answer>` 内 token）子集，因为 V\* 的增益集中在那里。

## 3. 指标与判读

| 指标 | 回答的问题 | 判读阈值（预登记） |
|---|---|---|
| **M1** TV(p_ℓ, p⁰)、TV(p_ℓ, p_text) 随 ℓ 的曲线 | 哪一层的读出最像"没看 crop"的分布；哪一层最像纯语言先验；p⁰ 与 p_text 自身距离多远（告诉我们 null 到底是"语言先验"还是"全图先验"） | 若 min_ℓ TV(p_ℓ, p⁰) < TV(p⁺, p⁰)（即某层比 anchor 自己更接近 null），候选成立 |
| **M2** 真 u 对 {r_j} 的最小二乘回归：权重 w_j 与 R² | crop 增量是哪些 block 加进去的，能解释多少；顺便检验 IR 选 [12,20) 对不对 | R² ≥ 0.5 → 存在可读出的"crop 块"，可做加权区间 IR；R² < 0.2 → 线性读出无望 |
| **M3** 对每个候选 p̂：corr(û, u)、TV(q̂, q_A)（q̂ ∝ p⁺·exp(β·û)，β=4，与 A 同） | 新目标与 A 的目标有多接近 | TV(q̂, q_A) 中位数 < 0.10 且 corr(û,u) > 0.7 → 进入训练；否则不训 |
| **M4** 对照：IRfl4 的 q（λ=4, [12,20)）与 q_A 的 TV | 给 M3 一个标尺：现在失败的目标离 A 有多远 | 候选必须明显小于它 |
| **M5** 答案位置子集上重复 M1/M3 | V\* 增益集中处是否更接近 | 同上 |

## 4. 决策

| 结果 | 动作 |
|---|---|
| M3 通过（某 ℓ 或某加权 block 集） | 实现 `teacher_target_mode=internal_prior`：û = log p⁺ − log p̂，q ∝ p⁺·exp(β·û)，β=4，tail 按 A（压缩后 tail 的 û=0）。先单次跑，TB>50 且 V\* ≥ 92 再补第二次。替换 `orch_ir3` / `orch_irc` 里的区间扫描臂 |
| M2 R² 高但 M3 不过 | 做"回归权重加权的 IR"（r = Σ w_j r_j）一臂，λ 按 TV 对齐 A 定 |
| 全部不过 | 关闭"单次前向线性读出"线；记录 p⁰ 的信息来自注意力重算这一事实；剩余候选回到 `null_free_line_summary` §5（文本先验前向、前缀共享） |

区间扫描（[8,24) λ=1 → [20,28) λ=1 在 hold 20814117；[20,28) λ=2 → [24,32) λ=2 在第三张 hold）**暂不取消**：探针若在 orch_ir3 启动前（约 14:00）出结果，按上表替换；否则第一个扫描臂照跑，不让卡空。

## 5. 成本与安排

## 7. 风险与边界
- **读出 ≈ p⁰ 不等于训练等价**：即使某层很像 p⁰，û 是"同一次前向里两个读出相减"，与 A 的"两次前向相减"在学生侧的梯度形态可能不同（p̂ 与 p⁺ 共享全部上游计算，噪声相关性更高）。探针只回答"像不像"，训练才回答"管不管用"。
- **logit-lens 的已知偏差**：中早层的残差经最终 norm + head 读出会偏向高频 token；M1 若在早层给出小 TV 需要与 p_text 对照确认不是这个伪影。
- **位置依赖**：D_t 用 real 前向的 h^L 算，p̂ 与 p⁺ 共享同一缩放；这是 IR 的口径，也是训练时唯一可得的口径。
