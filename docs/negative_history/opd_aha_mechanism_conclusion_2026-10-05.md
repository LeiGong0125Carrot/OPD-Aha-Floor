# OPD-Aha 到底在学什么：一句话结论与证据（2026-10-05）

> 讨论记录（用户 + 助手，10-05 13:10–13:30），在层先验探针（`ir_layer_prior_probe_plan_2026-10-05.md` §6）出结果之后形成。
> 口径：所有准确率为 gpt-oss-120b judge；探针数字来自 `probe_layer_prior/full_1005_1234/`（400 题，base 贪心回答，冻结教师 pair/null/text 三视图评分）。

## 1. 结论

**OPD-Aha（臂 A）学到的是：压制"没有证据时模型会乱说"的冲动。**
特权教师看到 GT 区域的 crop 之后，"没看清关键区域时会说什么"（p⁰）变得可识别；u = log p⁺ − log p⁰ 的负半边把这些先验驱动的描述压下去，学生学的是"证据不支持的话别说"。它不是从教师那里拿到正确答案。

## 2. 证据

| # | 证据 | 来源 |
|---|---|---|
| 1 | **只压不提即可**：suppression-only 臂（只保留 u 负半边）与完整 A 终点持平，V\* 91.62 同分；正半边非必要 | `vision-opd-sup-arm`（09 月）；季度总账 |
| 2 | **被压的是"看着全图但没看清关键区域时的猜测"，不是语言习惯**：TV(p⁺, p⁰) 均值 0.065，TV(p⁰, p_text) 0.23——p⁰ 离 p⁺ 比离纯语言先验近 3.5 倍 | 探针 §6 参照尺度 |
| 3 | **作用位置在"冲动"形成处，不在结论处**：答案字母位 TV(p⁺, p⁰) 仅 0.012–0.021、d_base 中位数 0.000；u 的质量集中在推理正文里描述感知内容的 token（样本 row 719："The sign on the ___"：看 crop → left 0.98，不看 → top 0.93） | 探针 §6 M5 与 §6.1 样本 1；与 Q-contrast 线在答案位做对比判负（Δans −8.5 nats 反向）互为印证 |

## 3. 两个限定

1. **压的是教师自己的冲动**。学生能迁移，前提是学生与教师共享同一种冲动——同一底座。这是自蒸馏成立的原因，也是学生参照（S/St）失败、学生做底座（S2）塌缩的原因：换了分布，"冲动"就不是同一个了。
2. **同一个 β 也放大与证据无关的风格差异**。探针样本 row 1706 首 token：p⁺ "The" 0.57 / "C" 0.39，p⁰ "C" 0.58 / "The" 0.31，Q_A 把 "The" 推到 0.986——u 在首 token 上编码的是"先解释再作答"的风格。这是 IRfl4、e1 等线一放大就出现回答变长、缺 `<answer>` 标签的来源；格式漂移要单独控制，不能靠调 β。

## 4. 对"去 null"方向的含义

- 这个"冲动"只存在于**另一次计算**（不看 crop 的前向）里：400 题探针显示单次 real 前向的残差流任何一层都读不出 p⁰（晚层 ≈ p⁺，中早层未成形，block 贡献的线性组合与 u 正交，R² 0.008）。
- 因此"内部找 null 的替代"在线性读出族内不成立；"用语言先验替代 null"与 A 的参照不是同一个量（证据 2）。
- 若仍要检验语言先验参照经训练后的效果，应直接用精确语言先验（纯文本教师前向或 `null_scope=all`）跑训练上界，而不是在内部找近似（待用户决定）。

## 5. 追加：u 里有没有可剥离的"风格分量"？（10-05 14:20，离线预检，判否）

讨论中提出的方案："u 当 reward，按 token 给 baseline"：q ∝ p⁺·exp(β·(u − b(v)))，b(v) = 该 token 的 u 在数据流上的均值（在线 EMA），把跨题一致的风格分量去掉、只留图像特异的证据分量。
预检（同 400 题探针数据，`Vision-OPD-setup/probe_u_dump.py` + `probe_baseline.py`，fit 200 题估 b，ω = 教师在 top-K 上的质量加权）：

| | fit | selection | held-out |
|---|---|---|---|
| b(v) 解释的 u 能量 | 15.2% | −7.3% | −6.3% |

u 几乎完全是题目特异的，token 粒度上不存在跨题一致分量；新题上减 b 反而加能量。去均值后实词能量份额 41.9% → 49.2% 的上移来自噪声，不是信号集中。首 token 的"The vs C"是位置效应而非 token 效应（能量 0.53 → 0.41）。
一个小伪影：|b| 最大的词含 zoom (+1.07)、cropped、Based、To——教师 prompt 的 "Zoomed-in view of the key region" 措辞经 u 泄漏给看不到这行字的学生，能量占比 <1%。
**结论**：baseline 方案不进训练；A 的格式/风格漂移不能按 token 统计剥离。按位置/词类的规则式 mask 用户判为缺乏创新，亦不做。
剩余方向（待用户定）：前缀共享双分支（工程，p⁰ 逐 bit 同 A，约 1.1× 前向）；语言先验上界臂（`null_scope=all`，零代码）。
