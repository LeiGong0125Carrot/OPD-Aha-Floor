# 镜像探针：全图前向的 hidden states 能否还原特权（pair）偏好？（2026-10-05）

> 用户 10-05 14:40 提议：若从**全图前向**（学生视图，无 crop）的内部状态能读出接近 pair 视图的 token 偏好，则 OPD-Aha 算法可以完全不用特权前向；若由此超过 Vision-OPD（V0），就是独立贡献。用户决定：**先测零参数版本；暂不考虑带参数的映射**（提前学映射又成了工程问题）。
> 数据：与 `ir_layer_prior_probe_plan_2026-10-05.md` §6 相同的 400 题、相同 base 贪心回答、相同学生 top-100 支持集；脚本 `Vision-OPD-setup/probe_full_to_priv.py`（零参数读出）、`probe_repr_attn.py`（表征相似度 + 注意力，见 §3）。

## 1. 零参数读出（10-05 14:55，400 题，55,364 位置）

设定：全图前向（学生视图）采 33 个边界残差 h^ℓ，final-D / own-D 读出 p̂_ℓ；锚 = p_full（全图输出）。两种目标：(i) p̂_ℓ 直接当 V0 目标，比 TV(p̂_ℓ, p⁺)；(ii) 以 p_full 为锚、p̂_ℓ 为"参照"，Q̂ = softmax(log P_full + β(log P_full − log p̂_ℓ))，β∈{1,4}，比 TV(Q̂, p⁺) 与 TV(Q̂, Q_A)。基线 = 不做任何事：TV(P_full, p⁺)。

| 子集 | 基线 TV(P_full, p⁺) | 最优层读出 TV(p̂_ℓ, p⁺)（ℓ<32） | 最优 Q̂ 的 TV(Q̂, p⁺)（ℓ<32） | 逐位置 oracle（事后选层） |
|---|---|---|---|---|
| 全体 | 0.081 | 0.344（own-D ℓ=31） | 0.135（ℓ=0, β=1） | 0.071 |
| 活跃位（≥75% 分位） | 0.258 | 0.526（ℓ=31） | 0.341 | 0.186 |
| 答案位 | 0.024 | 0.058（ℓ=31） | 0.025（ℓ=3, β=1） | 0.012 |

逐层形状与上午完全镜像：ℓ≤20 的读出 TV≈0.995（未成形），ℓ=24 0.976，28 0.84，30 0.68，31 0.36，32 = p_full。**没有任何一层读出比当前输出更接近 p⁺**；用读出做参照外推的目标（β=1、4）全部比不纠正更远（β=4 时 ℓ=31 达 0.60）。逐位置事后选最优层/β 的 oracle 也只从 0.081 降到 0.071（活跃位 0.258→0.186），且不可部署。
**判定：零参数版本判负。** 与上午的对称结论合在一起：在 Qwen3.5-4B 的单次前向里，响应位置的残差流线性读出既不含"没看 crop 时的偏好"，也不含"看了 crop 后的偏好"；两者都只在各自那次前向的最终层出现。

## 2. 对两条镜像结论的统一解释

残差流在响应位置上是"当前这次前向正在表达的内容"的工作区，不是"所有可能输入下会说什么"的储存库。中早层的内容在词表坐标下未成形（logit-lens 读出 TV≈1），晚层已被本次输入完全决定；反事实（换一个输入会说什么）只能靠换输入再算一次得到。这与 `opd_aha_mechanism_conclusion_2026-10-05.md` §4 的结论一致。

## 3. 表征相似度与注意力（用户 10-05 15:00 追加的问题）

待填：全图前向与 pair 前向在响应位置上逐层的 cos(h_full, h_pair)、相对差 ‖Δ‖/‖h_pair‖、Δ^ℓ 经最终 head 读出与真偏好差（z⁺ − z_full）在 top-K 上的 ω 相关；8 个 full-attention 层上响应位置对全图 GT 框区域的注意力集中度（相对框面积的 lift），以及 pair 前向对 crop token 的注意力质量。
