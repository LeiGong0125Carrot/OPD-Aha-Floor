## 1. 这条线的三个臂

全部以完整 OPD-Aha（A）为底座：q ∝ p⁺·exp(β·u)，β=4，u = log p⁺ − log p⁰。
轨迹状态来自实际采样 token 的视觉冲突 c_t = [−u_t(y_t)]₊（realized-token，精确，不受 top-k 支持集影响）。

| 臂 | 目标 | 轨迹状态 s_t | 作用位置 | 代码 |
|---|---|---|---|---|
| **Ahm** | q ∝ p⁺·exp(β·u⁺ + β(1+s_t)·u⁻) | h_t = H̄_t/(H̄_t+κ)，H̄_t = 前缀均值冲突 | 负半边 | `hist_mode=mean`，`9efb5b6` |
| **Ahf** | 同上 | h_t·f_t·η_t，f_t = F̄_t/(F̄_t+κ)，F̄_t = 严格后缀均值冲突；η_t = 0 表示该 rollout 被长度截断 | 负半边 | `hist_mode=hf`，`02fa4c2` |
| **X1** | q ∝ p⁺·exp(β(1+s_t)·u⁺ + β·u⁻) | 与 Ahm 同 | **正半边** | `hist_half=pos`，`bea75c6` |

κ = 0.10（≈ 实测平均 c）。Ahm 与 Ahf 的区别只在 s_t 是否乘未来门；X1 与 Ahm 的区别只在 β_t 作用于哪一半。

## 3. 推论

### 3.1 额外抑制越多，TB 越低；V\* 对此不敏感

| | Δβ | TB 峰值 | TB 池化 | V\* 峰值 |
|---|---|---|---|---|
| A | 0 | 49.88 – 51.60 | 49.22 | 91.6 – 94.8 |
| Ahf | ≈0.4 | 51.60 / 50.62 | 49.14 | 93.72 / 92.67 |
| Ahm | ≈1.55 | 48.64 / 49.88 | 47.94 | 94.24 / 93.19 |

TB 随 Δβ 单调下降；V\* 三者都在 A 的区间内。**在 A 的目标上追加抑制，不会换来 TB。** 与 sup 家族的结论一致：sup 家族（去掉正半边）TB 低 1.5、V\* 低 3；Ahm 把历史调节放回 A 底座后 V\* 的代价消失，但 TB 仍不涨。

### 3.2 Ahm 的 TB 丢在 OCR 和 Ordering，不只是关系推理

此前假设"TB 短板在关系推理类"。分类别数据只部分支持：Ahm 相对 A 的最大损失是 **OCR −4.9**（感知类），其次才是 Ordering −3.4、Contact −1.4；Comparison 持平。同时 Physical State +5.3。
OCR 恰好也是 sup 家族丢分最多的类别之一（B −1.7、C −3.9、D −5.1）。**加强负向抑制对 OCR 有系统性伤害**，一个可能的解释是：文字识别类 token 在 null 视图下也常有较高概率（语言先验强），u 为负，于是被过度压低。这一点值得在 X1 的分类别结果里对照。

### 3.3 Ahf 与 A 持平，但分不清是"未来选对了位置"还是"罚得少"

Ahf 的 Δβ 只有 Ahm 的 1/4，目标本身就更接近 A；逐题翻转只有 1–3 题，池化 TB 相差 0.08。设计文档 §12.4 预先提醒过这个盲区。按新规则不再用常数剂量对照拆分，只能靠改变作用方式来回答（见 §4）。

### 3.4 历史 / 未来信号大半在按 rollout 分剂量，轨迹内变化有限

Ahf 的 h·f 方差分解：rollout 之间约 60%，轨迹内约 40%。前缀均值和后缀均值在轨迹中段都收敛到整条 rollout 的平均冲突 c̄，h·f ≈ g(c̄)²，只在首尾有斜坡。设计文档 §8.5 / §12.3 担心的常数化部分成立。这类"均值门"天然更像一个 per-rollout 权重。

### 3.5 Ahm / Ahf 均在 step50 达到峰值

Ahm 两次、Ahf 两次的 TB 峰值都在 step50；Ahfr2 的 TB 一路上行（46.2 → 48.4 → 50.6）。A 的峰值位置分散在 30–50。只记录现象，不以步数为变量。

### 3.6 对"在完整 Aha 上结合历史与未来能否提升"的判断

**与 A 持平已经做到（Ahf），"超过"没有证据。** 注意不能拿论文的 V\* ≈ 92 作比较基准：同一流程下我们的 A 池化 92.84、峰值最高 94.76，Ahf 的 93.72 落在 A 区间之内，池化反而低 0.8。

现有证据排除的是"历史 / 未来 → 更大的负向剂量"这一条出口；信号本身的信息量没有被否定。两种尚未检验、且与 Ahm/Ahf 机制不同的用法：

1. **改变作用方向而非强度（X1，训练中）**：轨迹积累了视觉冲突时，加强对视觉支持 token 的提升，负半边保持 A。§3.2 给出一个可检验的预测：若"负向抑制伤 OCR"成立，X1 的 OCR 不应低于 A。
2. **把"历史有冲突、未来已平稳"识别为自我纠正（未实现）**：在乘积门里这个组合被当作"收回惩罚"，但它可能恰恰标记了模型自行纠正的位置（Aha 时刻），应当加强学习该位置的 target 而不是减弱。这是把历史 / 未来当作"挑选学哪些位置"的信号，而不是"调多大力度"。

## 5. 方法思路的一句话表述与术语（10-03 下午讨论）

> **保留完整 OPD-Aha 的目标和训练方式不动，用学生自己轨迹上已经发生的视觉冲突（前文累积的、后文持续的）来决定在哪些位置、往哪个方向额外修正监督信号，而不是对所有位置用同一个固定强度。**

- **监督信号** = 目标分布 q_t(v) ∝ p⁺_t(v)·exp(β·u_t(v))，u_t(v) = log p⁺_t(v) − log p⁰_t(v)；学生用 JSD 拉向 q。
- **固定强度** = β（原版恒为 4，对所有位置、所有 token、所有 rollout 相同）。
- **正半边 / 负半边** = 词表上 u_t(v) > 0（被视觉证据支持）/ u_t(v) < 0（被视觉证据反对）的候选 token。公式上 β·u 拆成 β₊·max(u,0) + β₋·min(u,0)。
- **与"改 tilt 形状"的本质区别**：β_t 不是 u_t(v) 的函数，而是轨迹上**实际采样 token** 的冲突 c_k = [−u_k(y_k)]₊ 的函数（[B,T] 标量序列）。同一个 u_t(v)，放在一直贴合证据的回答里和已经偏离很久的回答里，放大倍数不同。tanh / floor / γ 改的是 exp(β·u) 的非线性形状，与当前位置的词表有关、与轨迹无关，本季已全部判负。

| 臂 | β₊（u>0） | β₋（u<0） | 一句话 |
|---|---|---|---|
| A | β | β | 原版 |
| Ahm / Ahf | β | β_t | 出错后多罚 |
| X1（训练中） | β_t | β | 出错后多拉回证据 |

## 6. 下一步候选 X2：正负两半解耦（10-03 下午讨论，未实现）

### 6.1 为什么"叠加 Ahm 和 X1"不是解耦

若 β₊ = β₋ = β(1+s_t)，等于整个 tilt 乘一个随轨迹变化的倍数，两边仍绑在一起，只是从全局固定剂量变成逐位置剂量。本季证据（Ahm 剂量轴、sup 家族）表明单纯调剂量换不来 TB。

### 6.2 已有证据给出的解耦方向

| 证据 | 含义 |
|---|---|
| Ahm：冲突多时加重压制 → TB 掉，OCR −4.9 | 压制负半边会误伤语言先验强、u 只略为负的 token（文字类最典型） |
| sup 家族：去掉正半边 → 关系推理掉 | 正半边承担"往哪个 token 走"的引导 |
| Ahf：压制越少越接近 A | 负半边的额外压制不是增益来源 |

合起来：**轨迹偏离视觉证据时，应加强"拉向证据"（β₊ 上调），同时减弱"推离错误"（β₋ 下调）**，而不是两边一起加。

### 6.3 候选形式：守恒解耦

$$
\beta_{+,t}=\beta(1+s_t),\qquad \beta_{-,t}=\beta(1-s_t),\qquad \beta_{+,t}+\beta_{-,t}\equiv 2\beta .
$$

- s_t 沿用 Ahm 的前缀均值冲突门（κ = 0.10），不引入新的可调量。
- **结构优势**：两边系数之和恒等于 2β，平均强度与 A 完全相同；无论 s_t 多大，总剂量不变，变化的只是"压制"与"提升"之间的分配。因此它不可能被解释成"罚得多 / 罚得少"（Ahf 留下的疑问），也符合"不靠调强度"的要求。
- 实现只需在 `counterfactual_hist_half` 上加一个 `split` 选项；现有 `neg` / `pos` 分支与守卫不变。

### 6.4 判读依赖 X1

X1 就是 X2 的一半（β₊ 上调、β₋ 不动）。
- X1 的 TB 不低于 A 且 OCR 不掉 → X2 是自然的下一步，且很可能更好（还把伤 OCR 的那一半收回）。
- X1 本身低于 A → 在 A 的目标上做逐位置的强度再分配不论哪个方向都不行，X2 也救不回来；转向 §3.6 第 2 种用法（用历史 / 未来挑选学哪些位置）。

## 7. 更远的问题：能否不依赖 visual-null 前向（OPD-Aha 作者的建议，10-03）

### 7.1 问题

OPD-Aha 作者的看法：若追求更高的 novelty 和独立性，值得探索**完全不做 visual-null 这一次额外前向**、也能达到相近效果的方法。
当前每步三次前向（实测：student 28 s、teacher-real 26 s、teacher-null 26 s，backward 46 s），null 占每步时间约 20%。

### 7.2 先纠正一个事实：A 的 null 不是语言先验（10-03 晚核对代码）

A 使用 pair 模式 + `counterfactual_null_scope=last`（`ray_trainer.py:732`）：教师的特权输入是 **[全图, crop]**，null 只把 **crop 换成纯色块，全图保留**。因此

- p⁺ = 教师(全图 + crop)，p⁰ = 教师(全图 + 空白块)；
- u = log p⁺ − log p⁰ 衡量的是 **crop 在全图之外额外带来的信息**，不是"有视觉 vs 没视觉"。

**A 之所以有效，靠的不是去掉语言先验，而是精确隔离出特权信息的增量。** 这改变了 §7.3 中候选 (b) 的地位（见下）。

### 7.3 null 前向在当前方法里提供了什么

| 用途 | 依赖 null 的量 | 若无 null 的后果 |
|---|---|---|
| 目标形状（方向） | u_t(v)，决定哪些 token 抬、哪些压 | 回到 StdOPD（V0）：TB 49.38 / 48.64，V\* 87.4–88.5，V\* 低 A 约 5 点 |
| 轨迹状态 | c_t = [−u_t(y_t)]₊ | Ahm / Ahf / X1 / X2 的 s_t 全部不可计算 |

**tilt 相对 V0 的增益是本季唯一干净的正向分化**（TB +1.9、V\* +4–6）。去掉 null 必须找到另一个能给出"特权增量方向"的参照分布。

### 7.4 候选替代参照（均未实现、未验证）

| 候选 | 参照分布 | 额外前向 | 衡量的东西 | 顾虑 |
|---|---|---|---|---|
| (a) 学生自身 | u_S = log p⁺ − log p^S，学生在全图上的分布（训练本来就要算） | **0** | 特权教师比全图学生多知道的：学生看全图 ≈ 教师看全图，差异 ≈ crop 增量 + 两个模型的差异 | 混入模型差异；随训练推进学生逼近教师、信号衰减；与 OPD extrapolation / contrastive 思路相近，需查新 |
| (b) 教师-全图 | u_T = log p⁺ − log p^{T,full} | 1 | **这就是 A 现在的 null**（只差一个空白图块），不是新候选 | — |
| (c) 文本先验 | u_lang = log p⁺ − log p_lang，教师只看文字不看任何图 | 1，但 prompt 从约 3400 token 降到约 200，**成本约 1/10** | 全部视觉信息（全图 + crop） | 见 7.5 |
| (d) 旧学生 / EMA | u_old = log p⁺ − log p^{S,old}，用 rollout 时的 old_log_prob | 0 | 与 (a) 同源 | 随训练趋同 |
| (e) 轨迹内自参照 | 不构造词表级 u，只用同一问题多条 rollout 之间的分歧作为轨迹状态 | 0 | 只剩位置选择 | 丢掉词表级方向；n2 下只有两条 |

### 7.5 "类似 null 的语言先验"能否达到 OPD-Aha 水平（10-03 晚讨论）

用文本先验做参照，正半边会变成"任何视觉信息支持的 token"，包括全图本身就能看出来的东西，不再聚焦在 crop 增量。

量化参考：Qwen3-VL-8B **完全不看图**在 TreeBench 上得 38–39%（随机 25%，4B 看图 44.9%，`eval/treebench_probe/8B_blind.log`）。语言先验在 TB 上很强；粗略分解为：语言先验 ≈ 38、全图再给 ≈ 7、crop 增量只剩几分。u_lang 会把中间那 7 分的 token 与最后几分混在一起放大，而学生本来就看全图，这部分对它是冗余的，真正缺的 crop 增量反而被稀释。

| 参照 | 预期 |
|---|---|
| 文本先验 (c) | V\* 可能守住（V\* 考的是"看没看到小物体"，任何视觉支持都对）；**TB 风险大**（关系推理和 OCR 靠全图，会被当成"视觉支持"一起放大） |
| 学生自身 (a) | 最接近 A 的机制：保留"全图已知、crop 未知"的结构，且零前向；是作者所说"不依赖额外一次 null"的唯一真正零成本候选 |

**判断**：
1. 语言先验参照：V\* 有机会，TB 大概率不行。
2. 更可能达标的零成本方案是学生自身分布 (a)。
3. **novelty 不会来自换参照**：图像扰动做参照 = VCD，文本先验做参照 = M3ID / ICD 一类的解码方法，均已有文献。独立性只能来自训练时的轨迹机制（Ahm / X1 / X2 这条线）加上零前向的参照，而不是参照本身。

### 7.6 建议的检验顺序（与 X1 / X2 正交，均为"A 的 tilt 换参照、其他不变"的两次对照）

1. **先跑学生自参照 (a)**：u_S = log p⁺ − log p^S。学生 top-k 分布已在 loss 函数内，代码改动最小；c_S,t = [−u_S,t(y_t)]₊ 同样可得，Ahm / X1 / X2 的轨迹机制可原样迁移。
2. 若 (a) 守不住 V\*，再跑文本先验 (c)：需给 null 前向去掉图像 token 并重构 prompt，工程量中等；response 位置对齐不受影响。
3. 不与 X2 混在同一个臂里（单变量纪律）。

### 7.7 候选 S：完全不用 visual null，以学生分布为参照（10-03 晚讨论，未实现）

**约束**：从头到尾不做任何 null 前向，也不在预热期用 null 训练预测头（§7 中"把反事实学出来"的方案因此划掉）。

#### 7.7.1 定义

OPD-Aha 的唯一改动：u 中的 p⁰ 换成学生自己的分布 p^S，其余全部不变。

$$
u^S_t(v)=\log p^+_t(v)-\log p^S_t(v),\qquad
q^S_t(v)\propto p^+_t(v)\exp\big(\beta\,u^S_t(v)\big)=\frac{(p^+_t(v))^{1+\beta}}{(p^S_t(v))^{\beta}} .
$$

- p⁺：冻结教师看 [全图, crop]，本来就要算；p^S：学生看全图，算 JSD 本来就要算（目标构造时取 detach）。
- β=4、JSD α=0.5、top-100 + tail 支持集、pair 视图、训练配置全部沿用 A。每步少一次教师前向（约 20% 时间）。
- 位置级状态随之改为 c^S_t = [−u^S_t(y_t)]₊ = [log p^S_t(y_t) − log p⁺_t(y_t)]₊，即"学生生成了一个自己比教师更偏好的 token"。
- 配置建议：`counterfactual_reference = null | student`，默认 `null` 保证 A 逐比特不变；tag `pair_S[r2]_6karmA`。第一轮按单变量纪律**只换 u，不叠轨迹机制**。

#### 7.7.2 与 Vision-OPD、OPD-Aha 的关系

| 方法 | 目标 q | 用到的分布 |
|---|---|---|
| Vision-OPD（V0） | p⁺ | 教师 |
| OPD-Aha（A） | p⁺·exp(β(log p⁺ − log p⁰)) | 教师、null 教师 |
| **S** | p⁺·exp(β(log p⁺ − log p^S)) | 教师、学生 |

S 的目标不是教师本身，而是**从学生出发、穿过教师、再外推 β 倍的点**：log q^S − log p^S = (1+β)(log p⁺ − log p^S) + const。

#### 7.7.3 数值例子（crop 里是条纹；学生凭语言先验倾向菱形；β=4）

| 时刻 | p⁺ striped / diamond | p^S striped / diamond | V0 odds | A odds（p⁰ = 0.3/0.6 不变） | **S odds** |
|---|---|---|---|---|---|
| 第 0 步（学生 = 教师权重，只差 crop） | 0.6 / 0.3 | 0.3 / 0.6 | 2 | 512 | **512** |
| 学会一半 | 0.6 / 0.3 | 0.45 / 0.45 | 2 | 512 | **32** |
| 追上教师 | 0.6 / 0.3 | 0.6 / 0.3 | 2 | 512 | **2**（= V0） |
| 超过教师 | 0.6 / 0.3 | 0.8 / 0.2 | 2 | 512 | **0.125**（反向拉回） |

odds = (p⁺ 比)^(1+β) × (参照比)^(−β)。

#### 7.7.4 三点区别

1. **S 是会退火的 Aha。** 第 0 步 p^S(全图) 与 p⁰(全图 + 空白块) 同义，S ≡ A；随着学生吸收 crop 证据，目标自动退回 Vision-OPD。A 的目标始终不变。
2. **S 有 A 没有的刹车。** 学生在某 token 上比教师更极端时，S 把它拉回教师；A 不会。可能防过度尖锐化，也可能限制学生超越教师。
3. **S ≠ Vision-OPD。** V0 拟合 p⁺；S 在第 0 步比 p⁺ 尖 (1+β) 倍，且尖的方向是"教师偏离学生的方向"，不是单纯把 p⁺ 变尖（后者 = γ 臂，已测，软分布贡献约 1.4 点）。两者只在学生完全追上教师时重合。

**一句话**：OPD-Aha 把"视觉反事实"当放大方向；S 把"学生尚未吸收的教师知识"当放大方向，起点相同，终点回到 Vision-OPD。

#### 7.7.5 预判与风险

- S 的外推力集中在训练前期，后期趋于 V0。能否守住 V\* 93.5，取决于 A 的增益是前期形成的还是靠 51 步持续推力——现有数据回答不了，只能跑。
- 尾部 token 上 β·u^S 可能很大，由现有 top-100 + tail 支持集兜住；需监控 target_tv、target_entropy 与 A 的差异。
- 外推形式的目标在蒸馏文献中有近似先例（对教师做 extrapolation），上报前需查新；novelty 的落点是"零 null 前向 + 可接轨迹机制"，不是外推本身。

#### 7.7.6 其他零 null 方案的定位

| 方案 | 能给什么 | 结论 |
|---|---|---|
| 教师注意力落在 crop token 上的比例 | 位置级"这里用了视觉" | 不能重塑目标；flash-attn 下取不到，退回 eager 代价大 |
| 教师–学生置信度差 | 位置级 | 是 u^S 的位置级压缩版，不如直接用 c^S |
| 多条 rollout 分歧 | 位置级 | n=2 太粗 |

词表级方向在零 null 约束下只有 S 一条路；其余只能做"挑位置"。
