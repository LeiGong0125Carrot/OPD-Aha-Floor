## 1. 这条线的三个臂

全部以完整 OPD-Aha（A）为底座：q ∝ p⁺·exp(β·u)，β=4，u = log p⁺ − log p⁰。
轨迹状态来自实际采样 token 的视觉冲突 c_t = [−u_t(y_t)]₊（realized-token，精确，不受 top-k 支持集影响）。

| 臂 | 目标 | 轨迹状态 s_t | 作用位置 | 代码 |
|---|---|---|---|---|
| **Ahm** | q ∝ p⁺·exp(β·u⁺ + β(1+s_t)·u⁻) | h_t = H̄_t/(H̄_t+κ)，H̄_t = 前缀均值冲突 | 负半边 | `hist_mode=mean`，`9efb5b6` |
| **Ahf** | 同上 | h_t·f_t·η_t，f_t = F̄_t/(F̄_t+κ)，F̄_t = 严格后缀均值冲突；η_t = 0 表示该 rollout 被长度截断 | 负半边 | `hist_mode=hf`，`02fa4c2` |
| **X1**（排队中） | q ∝ p⁺·exp(β(1+s_t)·u⁺ + β·u⁻) | 与 Ahm 同 | **正半边** | `hist_half=pos`，`bea75c6` |

κ = 0.10（≈ 实测平均 c）。Ahm 与 Ahf 的区别只在 s_t 是否乘未来门；X1 与 Ahm 的区别只在 β_t 作用于哪一半。

## 3. 推论

### 3.1 额外抑制越多，TB 越低；V\* 对此不敏感

把 A 底座上的三个点按额外负向剂量排列：

| | Δβ | TB 峰值 | V\* 峰值 |
|---|---|---|---|
| A | 0 | 49.88 – 51.60 | 91.6 – 94.8 |
| Ahf | ≈0.4 | 50.62（r2；r1 待出） | 92.67 |
| Ahm | ≈1.55 | 48.64 / 49.88 | 94.24 / 93.19 |

TB 随 Δβ 单调下降；V\* 三者都在 A 的区间内。**在 A 的目标上追加抑制，不会换来 TB。** 这与 sup 家族的结论一致：sup 家族（去掉正半边）TB 低 1.5、V\* 低 3；Ahm 把历史调节放回 A 底座后 V\* 的代价消失了，但 TB 仍然不涨。

### 3.2 Ahf 好于 Ahm，但分不清是"未来选对了位置"还是"罚得少"

Ahf 的 Δβ 只有 Ahm 的 1/4，目标本身就更接近 A。设计文档 §12.4 预先提醒过这个盲区（Δβ^{HF} ≤ Δβ^H，HF 优于 H 可能只是平均抑制更弱）。按新规则不再用常数剂量对照拆分，只能靠改变作用方式来回答（见 §4）。

### 3.3 历史 / 未来信号大半在按 rollout 分剂量，轨迹内变化有限

Ahf 的 h·f 方差分解：rollout 之间约 60%，轨迹内约 40%。原因是前缀均值和后缀均值在轨迹中段都收敛到整条 rollout 的平均冲突 c̄，h·f ≈ g(c̄)²，只在首尾有斜坡。设计文档 §8.5 / §12.3 担心的常数化部分成立。
含义：这类"均值门"天然更像一个 per-rollout 权重，真正的逐位置时间信用只占小头。

### 3.4 Ahm / Ahf 都在 step50 达到峰值，51 步未收敛

Ahm 两次、Ahfr2 的 TB 和 V\* 均在 step50 最高，Ahfr2 的 TB 一路上行（46.2 → 48.4 → 50.6）。A 的峰值位置分散在 30–50。这提示负半边加强会放慢收敛；但按用户规则不改训练步数、不以步数为变量，只记录现象。

### 3.5 对"在完整 Aha 上结合历史与未来能否提升"的判断

**有可能，但不是通过加强抑制。** 现有证据排除的是"历史 / 未来 → 更大的负向剂量"这一条出口；信号本身的信息量没有被否定（c_t 一族仍是本季唯一有判别力的轨迹统计）。两种尚未检验、且与 Ahm/Ahf 机制不同的用法：

1. **改变作用方向而非强度（X1，已排队）**：轨迹积累了视觉冲突时，加强对视觉支持 token 的提升，负半边保持 A。动机：sup case study 显示正半边承担关系推理，而 TB 短板正在关系推理类（Ordering、Spatial Containment、Comparison）。
2. **把"历史有冲突、未来已平稳"识别为自我纠正（未实现）**：在乘积门里这个组合被当作"收回惩罚"，但它可能恰恰标记了模型自行纠正的位置（Aha 时刻），应当加强学习该位置的 target 而不是减弱。这是把历史 / 未来当作"挑选学哪些位置"的信号，而不是"调多大力度"。
