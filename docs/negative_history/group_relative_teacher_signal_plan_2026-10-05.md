# 计划：组内相对的教师信号能否替代 visual null？（2026-10-05，v0.1，待讨论）

> 来源：OPD-Aha 作者 10-05 建议——"OPD 都是 batch 训练，类似 GRPO，只不过不操作 reward，可以从本 batch 的别的样本拿信号"。用户读法：拿同 batch 其他样本的信号作为被压制对象。
> 本文只做计划与离线预检设计，不改训练代码，不提交训练作业。前置事实：`opd_aha_mechanism_conclusion_2026-10-05.md`（A 学的是压制没证据的冲动；u 集中在前期感知描述位置）、`full_to_priv_probe_2026-10-05.md`（内部读出两个方向判负）、探针线历史（教师信号区分对错轨迹 R_C 0.62）、EVT-neg（advantage 形式 0 胜 4 负）、rollout-disagree（判死）。

## 1. 读法与形式化

OPD 的 batch 结构：B 个 prompt × n 条 rollout（当前 n=2；历史上有 n=8 的运行）。同一组内：同一张图、同一个问题、不同回答 y^(1..n)；教师（pair 视图）对每条都已算过 p⁺_t^(k)。**不需要 null 前向**就能得到的组内信号：

| 信号 | 定义 | 粒度 |
|---|---|---|
| S1 序列似然 | s_k = mean_t log p⁺(y_t^(k)) | 序列 |
| S2 感知段似然 | 同上但只取前 30% 位置（u 质量集中处） | 序列 |
| S3 师生一致度 | −mean_t JSD(p⁺_t^(k), p^S_t^(k))（学生前向已有） | 序列 |
| S4 分叉点偏好 | 两条 rollout 共享前缀到第一个分叉位 t*；教师在 t* 的 p⁺ 同时给出两个分支 token 的概率：Δ = log p⁺(a_{t*}) − log p⁺(b_{t*}) | **token（免费）** |

组内相对量 A_k = s_k − mean_j s_j（或组内 z-score），类比 GRPO 的 advantage，但 s 来自教师而非环境 reward。

## 2. 可能的优势（讨论用）

1. **代价**：只要教师 real 前向，总代价 = Vision-OPD（2 次前向），比 A 省 1/3；不构造任何人工视图。
2. **信号性质不同于 null**：null 标出的是"一条回答内部哪些 token 依赖证据"；组内相对标出的是"同样证据下哪条回答更站得住"。后者能覆盖 null 覆盖不到的错误类型——看对了地方但推理走偏的轨迹（null 在这类位置 u≈0）。两者互补而非替代，这既是机会也是风险（见 §4）。
3. **被压制的是学生真实做出的行为**：负样本是同组里学生自己的另一条 rollout，而不是教师在人工 null 视图下的假想分布；"压制冲动"落在冲动实际兑现的轨迹上，与 DPO/GRPO 的在策略负样本一致。
4. **全部输入在分布内**：null 视图（均值色块 + "Zoomed-in view" 提示词）是分布外输入，已观察到提示词措辞经 u 泄漏给学生（zoom/cropped 的 b 值最高）；组内相对不引入任何分布外输入。
5. **S4 给出免费的 token 级定位**：分叉位之前两条 rollout 的 token 完全相同，教师在分叉位的一次前向同时含有两个分支 token 的概率；这是 batch 里唯一天然对齐到同一前缀的 token 级对比，不需要第二次前向。它回答"在哪一步走岔"而非"哪些词没证据"。

## 3. 离线预检（不训练，1 张卡约 3–4 小时）

**数据**：现有 rollout 转储 `rollouts/pair_ahaAn8sp1_6karmA/{1..5}.jsonl`（n=8，48 prompt/步，前 5 步策略 ≈ 初始；共 240 组 × 8 = 1,920 条），以及 n=2 的 `pair_ahaAn2_6karmA` 同步数；`score` 字段为 None（无奖励训练），对错用规则从 `output` 提取选项字母与 `gts` 比对（无法提取记 missing，单列）。若 n=8 转储不足，用 vLLM 对 300 题各采 8 条补齐（30 分钟）。
**计算**：每条 rollout 做教师 pair 前向与学生（初始权重、全图）前向，得 S1–S3；每组按前缀找分叉位得 S4；同时算 null 前向得 Σ|u| 作参照（仅校准，不进候选）。
**指标（预登记）**：
- G1：含对错混合的组占比（n=8 与 n=2 各报）。无混合的组没有组内信号。
- G2：混合组内各信号区分对/错 rollout 的 AUC（配对：组内任取一对一错），S1–S4 分别报；null 参照 Σ|u| 也报。
- G3：组内相对量与正确性的 Spearman（跨组 pooled）。
- G4：S4 的分叉位统计——分叉位相对位置分布、分叉位的教师偏好与最终对错的一致率。
**门槛**：G1 ≥ 1/3（n=8）且某个 S 的 G2 ≥ 0.70 → 进入 §4 设计；G2 全部 < 0.65 → 本线关闭（教师在序列级没有足够分辨力，与探针线 R_C 0.62 一致）。

## 4. 若通过：目标函数候选（只实现一个先跑）

| 候选 | 形式 | 风险 |
|---|---|---|
| T1 组内加权 V0 | 每条 rollout 的蒸馏损失乘 w_k = softmax_j(A_j/τ)，目标仍是 p⁺ | 最保守；可能只是 V0 ± 噪声 |
| T2 符号化 | A_k>0 的 rollout 正常蒸馏；A_k<0 的 rollout 对其 token 做反向项（压制） | EVT-neg 历史：advantage 形式 0 胜 4 负、塌缩 |
| T3 分叉位对比 | 仅在分叉位 t* 用 Δ 构造 Aha 式目标 q ∝ p⁺·exp(β·Δ·1[v=a]) 等 | 信号稀疏（每组 1 个位置）；与 rollout-disagree 的边界要划清 |

全部与 A 的区别：无 null 前向；与 V0 的区别：组内相对加权/压制。评判口径不变（TB>50、V\* 92–93，×2）。

## 5. 风险与边界
- 教师序列级分辨力弱（R_C 0.62）是最大风险；预检 G2 直接测。
- n=2 时组内只有一对，信号稀疏；n=8 历史上末端崩（n8 vs n2 反转）。
- advantage/负权重形式在本设定下有系统性失败史，T2 需要最严格的守卫。
- 组内相对回答的是"哪条更好"，不是"哪些 token 没证据"；即便成功，它与 OPD-Aha 的机制不同，不应被描述为 null 的近似。
