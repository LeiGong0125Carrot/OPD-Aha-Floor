# Rollout-Disagreement 探针终审：假设否定 — 2026-09-24

**结论：rollout 间的特权 discrepancy 是高度一致的，n=8 的梯度平均是有效降噪，不是信号稀释。**
因此 n=8 三个臂（ahaAn8 48.15 / supn8 48.64 / stn8 46.91）在 TreeBench 上系统性低于所有
n=2 臂（峰 49.1–51.4）这件事，**不能**用"rollout 分歧互相抵消"解释，需要另找原因。

配置：16 行 pair 数据 × 8 rollout = 128 条轨迹、**17797 个 token 位置**；
student = teacher = base 权重（step-0，discrepancy 纯由视图差异产生）；单卡约 4 分钟。
代码 `probing/probe_rollout_disagree.py` + `analyze_rollout_disagree.py`（commit 8c0db3a）。

## 一、主结果

指标 `R_n = ‖mean_i g_i‖ / mean_i‖g_i‖`，其中 `g_i = Σ_t (p_S,t − q_t)` 是
**KL(q‖p_S) 对 student logits 的精确梯度**（非代理）。标定点：完全同向 = 1、
完全独立 = 1/√n、成对反向 = 0（三点均在单测中机器验证）。

| | 实测 | 独立基准 | 实测/基准 |
|---|---|---|---|
| **R_8** | **0.723**（CI [0.701, 0.745]） | 1/√8 = 0.354 | **2.04×** |
| R_2 | 0.879 | 1/√2 = 0.707 | 1.24× |

**全部 16 行的 R_8 落在 [0.661, 0.820]**，没有一行接近独立基准，更没有任何一行低于它
（低于才意味着抵消）。预登记判据 R_8 ≥ 0.70 → **强 agreement**。

辅助读数：`tail mass` 中位数 0.00003（support 覆盖充分，top-100 几乎无泄漏）；
`CV(C_tgt)` = 0.180 ≪ 0.5（8 条的信号**强度**也不分散）；位置剖面 Spearman = 0.510
（8 条的 discrepancy 沿相对位置的形状中度一致）。

### 自洽性检验（这是结论最硬的一层）

若 `g_i = μ + ε_i`（μ = 共同信号，ε 独立），则 `R_n = √(1+ρ/n)/√(1+ρ)`，ρ = 噪声/信号能量比。
用 R_8 = 0.723 反解得 **ρ ≈ 1.20**，代回预测 **R_2 = 0.853**，实测 **0.879** —— 吻合。
两个独立测得的量被同一个单参数模型同时解释，说明这不是偶然数字。

由此：**共同信号占梯度能量约 45%，独立噪声约 55%；n=8 把噪声压到 6.9%。**
n=8 在数学上确实在做它该做的事。

### 子假设"TreeBench 上分歧更严重"也无支持

按 GT 框占比分层（中位 2.43%）：小框 R_8 = 0.732、大框 R_8 = 0.714 —— **无差异**。
框尺度正是 TB（5.19%）与 V\*（0.08%）的核心分野轴，这条轴上没有分歧度的梯度。

## 二、n=8 的 TB 劣势：嫌疑重新定向

disagreement 被排除后，剩下的主要候选是**学习率未随有效批大小缩放**：

- n=8 使每步的序列数从 96 → 384，梯度噪声按 √4 = 2 倍下降（本探针独立证实了降噪是真的）；
- 但 `lr` 在所有臂里恒为 2e-6，从未随批缩放；
- 经典 large-batch generalization gap：噪声本身有探索/正则作用，噪声减半而步长不变，
  在固定 51 步内有效探索变少。

**可检验预测**：n=8 + lr 8e-6（或 4e-6）应恢复到 n=2 的水平。一次训练即可验证（~11h@3卡）。

另一个待排除项是**新旧仓库差异**：三个 n8 臂跑在新 clone（483d70f + null_scope 补丁），
14 个 n2 臂跑在旧仓库。`ahaAn2`（新仓库 + A + n2，今晚出分）正是为隔离这一项而跑。

## 三、副产物：TGNVMT 的剂量定标（训练前的预警）

同一份 dump 顺带标定了 `trajectory_gated_negative_visual_mass_transfer.md` 的
Layer-2/3 全部状态量（定义在学生实际生成的 token y_t 上，17797 个位置）：

| 量 | mean | p50 | p90 | max |
|---|---|---|---|---|
| m_t 承诺度 | 0.866 | **1.0000** | 1.000 | 1.000 |
| o_t 视觉反对 | 0.110 | **0.0000** | 0.427 | 1.000 |
| e_t 冲突事件 | 0.078 | 0.0000 | 0.259 | 1.000 |
| C_t（EMA λ=0.8） | 0.077 | 0.051 | 0.182 | 0.628 |
| C_t（max 变体） | 0.201 | 0.128 | 0.499 | 1.000 |
| 单位转移量 unit | 0.100 | 0.057 | 0.274 | 0.533 |
| **Δ_t = TV(q,p⁺) EMA** | **0.0113** | 0.0020 | 0.035 | 0.287 |
| **Δ_t = TV(q,p⁺) max** | **0.0297** | 0.0048 | 0.092 | 0.438 |

**剂量对照：A = 0.250、supn8 = 0.065、stn8 = 0.059。**

⚠ **按文档参数（λ=0.8 纯 EMA、τ_u=0.5、β=4）会严重欠剂量**：
- 平均 Δ = 0.0113，**比 supn8 弱 5.8 倍、比 A 弱 22 倍**；
- 有效干预位置 Δ>0.01 仅 **27%**、Δ>0.05 仅 **6.3%** → **73% 的位置目标几乎恒等于 p⁺**，
  退化为普通特权蒸馏。这正是 stn8 "71% 位置空转"陷阱的重演形状。
- max 变体好一倍（Δ = 0.0297、40% 覆盖），仍比 supn8 弱 2.2 倍。

**结论：TGNVMT 若要训练，必须先重新定标**（候选旋钮：τ_u 0.5→0.2 放大 o_t；λ 0.8→0.5
加快响应；加全局增益 κ；或直接用 max 变体）。目标是让平均 Δ 落到 0.06 附近，
与 supn8 剂量匹配 —— 这样"轨迹门控"才是唯一变量。

### 两条对设计的实证反馈

1. **m_t 的 p50 = 1.0000**：一半以上位置学生生成的就是自己的 top-1，"承诺度门"在实践中
   几乎总是开着。它区分"真心 vs 采样意外"的作用远弱于设计预期 —— **o_t 才是主导因子**，
   m_t 近似可省（这也意味着 γ 这个旋钮几乎无效）。
2. **o_t 的 p50 = 0.0000**：一半以上位置视觉完全不反对（u ≥ 0），冲突事件本身高度稀疏。
   符合"错误分支是局部现象"的直觉，但也解释了为什么 C_t 的基线这么低。

### EMA 时序问题（定量确认）

单测第 8 组用设计文档 §5.4 的手算轨迹验证：在**错误诞生**的那个 token（`right`，
e_t = 0.723）处，EMA 给出 C = 0.151，而 `max(λC, e)` 变体给出 **0.723（4.8 倍）**。
纯 EMA 每步只吸收 (1−λ) = 20% 的当期事件，**刹车总在车开进去之后才踩下去**，
与"打断分支"的目标时序相反。建议第一版就用 max 变体。

## 四、诚实边界

1. **只测 step-0**（student = base）。训练中期 student 漂移后的一致性未测；若要外推需补
   ckpt 版探针（同一脚本换 `--model`）。
2. **HF generate ≠ 训练的 vLLM**。但训练的 8 条 rollout 本身就是**无 seed 的独立采样**
   （`ray_trainer.py:2414` prompt 复制 n 份、`single_turn_agent_loop.py:58` request_id=uuid4），
   我们要的是同分布样本而非逐 token 复现，分布级等价足够。
3. **R 是输出层（词表维）信号一致性**，不是参数空间梯度一致性 —— 中间层雅可比未计入。
   结论应表述为"输出层梯度方向高度一致"。
4. 16 行、单 seed；但 R 的 16 个 per-row 值离散度很小（0.661–0.820），CI 窄。
5. 本探针**不能**证明 lr-scaling 假设，只能排除 disagreement。
