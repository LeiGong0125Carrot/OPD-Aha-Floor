# P4：跨视图未来分歧（Cross-View Future Divergence, CVFD）——初步实验设计（2026-10-06，v0.1）

> 来源：10-06 下午讨论。背景：CFD-u = V0（07 §6）说明 u 的位置级幅度不能判定一个分歧是否重要；P2 关闭（05）说明"对错型"判别量（教师序列似然、师生一致度、null 幅度）在自蒸馏教师下没有分辨力（AUC ≤ 0.61）。本文把问题从"这条轨迹对不对"换成"**特权视图会不会导出一个不同的未来**"，用两条续写之间的分布分歧做判别量，不用 judge、不用标签、不做文本抽取。
> 范围：**只在每条 rollout 的第一个大分歧位置做一次分支**；先做离线预检，不训练。

## 1. 定义

记学生 rollout 为 $y^S$，前缀 $y_{<t^*}$ 在分支点 $t^*$ 之前与两条续写共享。

- **全图视图** $\pi_S(\cdot\mid x_{\text{full}},\cdot)$：学生当前权重 + 全图（即 rollout 引擎本身）。
- **crop 视图** $\pi_T(\cdot\mid x_{\text{full}},x_{\text{crop}},\cdot)$：同一权重 + pair 输入（与教师 real 视图相同的 prompt 构造，`_prepare_teacher_messages` + `bbox_images`）。v0.1 用**当前学生权重**作 crop 视图（EAD 的论据：与演化中的学生无状态差距；也避免再起一个冻结 vLLM 实例）；冻结初始权重作为对照变体。

从 $y_{<t^*}$ 出发：$y^S_{\ge t^*}$ 为学生原续写；$y^T_{\ge t^*}\sim\pi_T$ 为 crop 视图续写（温度与 rollout 相同）。

对视图 $V\in\{S,T\}$ 与续写 $y$，定义窗口内平均对数概率

$$\ell_V(y)=\frac{1}{|W|}\sum_{t\in W}\log\pi_V\big(y_t\mid y_{<t^*},y_{t^*:t}\big),\qquad W=\{t^*,\dots,\min(t^*+K,|y|)\}$$

**跨视图未来分歧**

$$D_{t^*}=\tfrac12\Big[\underbrace{\ell_T(y^T)-\ell_T(y^S)}_{\approx\,\mathrm{KL}(\pi_T\|\pi_S)\ \text{沿}\ y^T}+\underbrace{\ell_S(y^S)-\ell_S(y^T)}_{\approx\,\mathrm{KL}(\pi_S\|\pi_T)\ \text{沿}\ y^S}\Big]$$

是两条续写策略之间对称 KL 的单样本估计。$D$ 大：换了视图，未来互不认可——后果性分歧；$D$ 小：换了视图未来也差不多——非后果性（措辞/情态）分歧。它不要求教师正确，只要求教师不同。

两个变体同时报：$K=64$（近未来，TOPD 式）与 $K=\infty$（分支后全部 token）。

## 2. 分支点的选取

只取**第一个**满足条件的位置：

$$t^*=\min\{t\ge1:\ c_t>\tau\},\qquad c_t=[-u_t(y_t)]_+,\ u_t=\log p^+_t-\log p^0_t$$

- 用 $c_t$（crop 特异的 realized 冲突）而不用师生差 $\log p^+-\log p^S$：后者混入学生漂移，且随训练变化。
- $\tau$ 取 $c$ 的样本内 90 分位（离线报 80/90/95 三档）；没有位置过阈的 rollout 记为"无分支"，单列占比。
- $t\ge1$（t=0 无学生前缀）；$t^*$ 落在回答最后 8 个 token 内的不分支（没有未来可看）。
- 理由：OPD-Aha Figure 1a——前缀越短教师越能给出不同的未来（恢复率 75.8% → 6.0%）；第一个大分歧位置是 crop 视图最有机会"走另一条路"的地方。

## 3. 四项的来源与成本

| 项 | 来源 | 新增成本 |
|---|---|---|
| $\ell_S(y^S)$ | rollout 引擎返回的学生 log-prob | 0 |
| $\ell_T(y^S)$ | 教师 real 前向在学生 rollout 上的 realized log-prob（`teacher_outputs["log_probs"]`） | 0 |
| $\ell_T(y^T)$ | crop 视图生成 $y^T$ 时的 log-prob | 生成 $y^T$（从 $t^*$ 起，均长约 70% 回答长度） |
| $\ell_S(y^T)$ | 全图视图对 $y^T$ 打分 | 一次打分前向 |

无 judge、无标签、无文本解析。离线预检用现有 rollout 转储（`rollouts/pair_ahaAn2_6karmA/`、`pair_ahaAn8sp1_6karmA/`），生成与打分走 vLLM（prompt_logprobs）。

## 4. 离线预检（预登记）

**数据**：前 5 步的 rollout（策略≈初始），n=8 的 240 组 × 8 条优先（组内有对错混合的 64%），n=2 的补充。对错用 GT 判定，**GT 只用于评估 $D$ 的有效性，不进任何训练信号**。

**对照判别量**（同一批样本，同一分支点）：
- S1 教师序列似然（P2 口径，AUC 0.61）；
- $\bar F_{t^*}$：分支后学生后缀上 $c_t$ 的均值（Ahf 的未来门，无对照分支）；
- $\Delta_{\text{suffix}}=\ell_T(y^S)-\ell_S(y^S)$ 在窗口内的均值：**$D$ 去掉对照分支后的退化形式**，用来量化对照分支的增量。

**指标**：
- G1：有分支的 rollout 占比（按 τ 三档）；分支点相对位置分布。
- G2：$D$ 区分"学生错且 $y^T$ 对"与其余样本的 AUC；同时报"学生错"的 AUC。$K=64$ 与 $K=\infty$ 各报。
- G3：$D$ 与 $\Delta_{\text{suffix}}$、$\bar F$、S1 的 Spearman；若 $D$ 与 $\Delta_{\text{suffix}}$ 相关 > 0.9，说明对照分支没有增量。
- G4：crop 视图续写 $y^T$ 的答案正确率随分支相对位置的曲线（Figure 1a 的逐题版）。
- G5：$y^T$ 中 zoom / crop / zoomed-in 的出现频率（泄漏量，决定后续能否用 $y^T$ 做任何形式的监督）。

**门槛**：G2（学生错且 $y^T$ 对）≥ 0.70 且 $D$ 相对 $\Delta_{\text{suffix}}$ 的 AUC 增量 ≥ 0.05 → 进入 §5；G2 < 0.65 或增量 < 0.02 → 本线关闭，记录为"自蒸馏下跨视图未来分歧亦无分辨力"。

**成本**：1,920 条 rollout 各生成一段 $y^T$ + 一次打分，一张卡约 3–5 小时。

## 5. 若通过：训练臂（不改轨迹、不加离策略样本）

$D$ 只作**门**，不进损失值：
- **G-rollout**：$D_{t^*}>\delta$ 的 rollout 从 $t^*$ 起用 A 的目标，其余位置与未过门的 rollout 用 $p^+$（V0）。回答"后果性分歧之后的倾斜是否就是 A 增益的所在"。
- **G-β**：过门 rollout 在 $t^*$ 之后 β 不变，未过门 rollout 全程 β 减半。与 Ahm/Ahf 的区别：门来自对照分支，不是单边后缀冲突。
- 对照：用 $\Delta_{\text{suffix}}$ 替代 $D$ 做同样的门（无对照分支版本）。

不做：截断 $t^*$ 之后的蒸馏（与 CFD-u/IW-OPD 证据冲突，仅可作 V0 侧对照）；对 $y^T$ 做 SFT（离策略 + zoom 措辞泄漏，见 G5）。

## 6. 边界与已知风险

- 单样本估计方差大：$y^T$ 可采 2 条取均值；n=2 的 sibling 各算一次。
- 当前学生作 crop 视图会随训练漂移（教师冻结则不漂）；预检阶段策略≈初始，两者一致；训练阶段若上线，需同时报冻结变体。
- 只在 MCQ/短答案数据上评估有效性（G2 需要对错标签）；方法本身不依赖题型。
- 与 FTB 的区别：FTB 分支变量是教师**动作**、验证量是教师偏好比例 ρ（依赖教师序列级分辨力）；CVFD 分支变量是**特权输入**、验证量是两视图的互相似然，不依赖教师正确。与 TOPD 的区别：TOPD 比较师生各自短续写做对齐损失；CVFD 只用分歧做门。
