# P1 修订：预检之后的训练臂调整（2026-10-06，v0.2）

> 依据：`04_precheck_P1_P3_results.md`、`05_precheck_assessment.md`。本文只改 P1 的臂设计与判读，不改 `01_P1_counterfactual_flip.md` 的目标定义。P3 按 `05` 的结论不投训练；P2 等 G2。

## 1. 对两条"反证"的重新判读

### 1.1 首 token 翻转（32.8%）：不是 CFD 的问题，是定义域问题

OPD-Aha 的全部动机是**前缀条件下的反事实**：比较同一学生前缀 $y_{<t}$ 下有 / 无 crop 的教师差异。t=0 没有学生前缀，此处的 $p^+$ 与 $p^0$ 之差只反映教师 prompt 的措辞差异（"Zoomed-in view" 在场与否），与"证据和前缀的冲突"无关。预检里 t=0 的翻转（The→To / The→Based / The→D、original→zoom）全部是作答格式与提示词泄漏，正是这个原因。

所以 t=0 不在方法的定义域内，排除它是定义的一部分，不是规则式 mask。A 在 t=0 同样以 β=4 放大这个泄漏——这与机制结论 §3 限定 2（首 token 编码"先解释再作答"的风格）和 §5（zoom 的 $|b|$ 最高）一致。

**修订**：翻转集定义改为 $\mathcal F=\{t\ge1:\ a^+_t\neq a^0_t,\ a^+_t\notin\text{tail}\}$；并给 A 加一个对照 **A-t0**（t=0 处 β=0，其余同 A），检验 t=0 的倾斜是否是 A 格式漂移（缺 `<answer>`、裸选项）的来源。A-t0 若改善格式且 TB/V\* 不变，可直接作为 A 的修正版进论文。

### 1.2 翻转集外 59% 的提升质量落在实词：口径问题

被提升最多的实词是 both / clearly / especially / based 这类"看清后更笃定"的强调词（`04` F4）。它们在语义上是信心表达，属于风格通道而非证据内容，词类标注把它们归为实词只是分词器口径。F4 的"不符"不构成对 CFD 的反证。

### 1.3 真正的反证只有一条

A 的目标偏移 87.6% 落在翻转集外。γ=50 的证据只证明"argmax 够用"（全位置硬化、V\* 无损），不证明"6.4% 位置上的 argmax 够用"。CFD 丢掉的是不改变 argmax 的软重排；这部分是否承担增益，离线无法判断，必须训练。`05` 的"未获支持、轻度反证"是准确的，但三臂设计可以让这个赌注的两种结果都有判定力。

## 2. 修订后的三臂

| 臂 | 翻转集内 | 翻转集外 | 回答的问题 |
|---|---|---|---|
| **CFD**（主臂） | $\mathrm{softmax}(50\log p^+)$，$w=2$ | $p^+$，$w=1$ | 最小充分目标能否持平 A |
| **CFD-u** | $\mathrm{softmax}(\log p^+ + 4u)$（A 的目标），$w=1$ | $p^+$，$w=1$ | **与 A 的唯一差别 = 翻转集外的 87.6% 偏移**。≈A → 集外倾斜不必要；<A → 集外软重排是增益的一部分，P1 关闭 |
| **CFD-λ0** | $\mathrm{softmax}(50\log p^+)$，$w=1$ | $p^+$，$w=1$ | 与本季 γ=50 臂的唯一差别 = 集外是否锐化；分离"锐化位置"与"预算加权"两个因素 |

去掉原 γ=1/λ=1 臂（纯预算分配）：在 CFD-u 与 CFD-λ0 存在的情况下它不再提供独立信息。三臂均排除 t=0。判读优先级：**CFD-u 先出结论**，因为它对 A 的改动最小、对核心假设的检验最直接。

## 3. 新增指标与诊断

- `flip_frac_t0`、`flip_frac_tgt1`：t=0 与 t≥1 的翻转率分列（t=0 在修订后恒为 0，作为守卫）。
- `flip_a_plus_content_frac`：翻转后 $a^+$ 为实词的比例（预检 54.5%，训练中应保持或上升）。
- 评测期：首 token 行为分布（直接给字母 / "The" / "To" / "Based"）按臂统计，与 A、A-t0 对照——检验 CFD 是否把作答风格推向某一边。
- 格式合规率（缺 `<answer>`、裸选项、截断）必报。

## 4. 判读树

| CFD-u | CFD | 结论 |
|---|---|---|
| ≈A | ≈A | 翻转集外倾斜不必要、软分布不必要：CFD 成为去 β 的最小目标，进论文主方法 |
| ≈A | <A | 集外倾斜不必要，但翻转集内需要 $u$ 的软信息而非硬化：主方法改为 CFD-u |
| <A | — | 集外软重排承担增益；P1 关闭。记录为"目标重构的增益分散在不改变 argmax 的位置上"，与 γ=50 结果合并成机制结论 |

任一情形下 A-t0 的结果独立成立。

## 5. 实现差异（相对 `01` §4）

- 翻转集计算前对 `loss_mask` 做 `mask[:, 0] = 0`（仅用于翻转判定与加权，不改变 JSD 的有效位）。
- `counterfactual_target_mode` 增加 `flip_u` 取值（CFD-u）；`flip_gamma` 在该模式下忽略。
- A-t0：`counterfactual_t0_beta_zero: bool`，在 tilt 路径里把 t=0 的 β 置 0，其余逐 bit 同 A。
- 测试补三项：t=0 不进翻转集；`flip_u` 在 $\mathcal F$ 内与 A 的目标逐 bit 相同；`t0_beta_zero` 只改 t=0 列。
