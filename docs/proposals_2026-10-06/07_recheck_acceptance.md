## 2. 复核给出的新机制读法

最常见的翻转是 appears→is、on→in、is→has、visible→in、.→,；颜色 / 方位 / 尺寸词只占翻转与倾斜质量的 7–8%。即 **crop 带来的 token 级改变主要是情态与句法上的"更肯定"，而不是感知属性词的替换**。

这与 `opd_aha_mechanism_conclusion_2026-10-05.md` §1（"压制没证据时的冲动"）是同一现象的两面：null 教师在证据不清时使用 appears / visible / on 这类保留措辞，crop 教师直接断言。因此 $u$ 的主要内容是**以证据为条件的确定性校准**；"证据通道"与"风格通道"在 token 粒度上不可分，这对 A 与 CFD 同样成立。

对 CFD 的含义：翻转集更接近"情态决策集"而非"证据决策集"，`01` §1–2 的叙事需据此改写；赌注本身不变。

## 4. 补充（01:15）：把 hedging 诊断写成对"自锐化"替代解释的检验

§3 的诊断不只是机制描述，它是目前唯一一个零成本、且无论结果朝哪边都有判定力的实验，可以直接回答 OPSA（"Does On-Policy Distillation Really Distill?"，arXiv 2609.xxxx）对 OPD 增益来源的质疑：**OPD 的增益是否只是对低概率 token 的均匀抑制（自锐化）**。

### 4.1 两种解释在条件分布上的分歧

| | 均匀自锐化（OPSA 读法） | 以证据为条件的确定性校准（OPD-Aha 读法） |
|---|---|---|
| 保留措辞（appears / seems / visible / likely …）的减少 | 答对与答错的题上同等减少 | 集中在答对的题上；答错题上不减或略增 |
| 断言措辞（is / has / clearly / exactly …）的增加 | 两边同等增加 | 同上 |
| 对错差（Δ_correct − Δ_wrong） | ≈ 0 | 显著 > 0 |

整体词频可能无法区分两者，**对错差**才是判据。

### 4.2 对照臂（全部用已有评测输出，不训练）

| 臂 | 作用 |
|---|---|
| base、V0 | 零点 |
| A（9 ckpt 池化） | 主张 |
| **γ=50**（本季硬标签臂，3 次） | 全位置硬化 = 最接近"均匀锐化"的已有臂。若 γ=50 的对错差 ≈ 0 而 A 的 > 0，则"argmax 够用"（V\* 无损）与"证据条件化"（对错差）被分开：前者解释分数，后者解释机制 |
| sup 家族（B/C/D） | 只压不提；预测对错差小于 A（答错题上也减少，对应"自信地编造细节"） |
| Amis r1/r2 | donor crop 假证据；预测对错差接近 0 或为负 |

### 4.3 按类别分列（TB 10 类）

- **OCR**：若 A 的断言措辞上升但 OCR 正确率不升（甚至下降），即"过度肯定伤 OCR"的直接证据，解释本季所有更尖目标（Ahm / X1 / γ / IRfl4）都在 OCR 丢分的现象；文字 token 语言先验强、$u$ 略负，被当作"没证据的冲动"压掉。
- **关系推理**（Ordering / Comparison / Spatial Containment）：若 sup 家族在这些类别上对错差为负而 A 为正，与 `results_comparison` §3.1 的类别迁移形态对上。
- **Attributes**：预测各臂对错差都为正（局部属性是 crop 最直接支撑的内容）。

### 4.4 输出与判读

输出一张 臂 × {对, 错} × {保留, 断言} × 类别 的频率表（每千 token），加对错差及其 bootstrap CI（按题重采样）。

| 结果 | 结论 |
|---|---|
| A 对错差 > 0，γ=50 ≈ 0 | 机制主张成立且与自锐化可分；进论文机制节，作为对 OPSA 类质疑的回应 |
| A 与 γ=50 对错差都 > 0 | 证据条件化由 argmax 本身携带；CFD 系列的先验上调 |
| A 对错差 ≈ 0 | 该读法只在教师目标层面成立，未迁移到学生；与 §3 末句一致，照记 |
