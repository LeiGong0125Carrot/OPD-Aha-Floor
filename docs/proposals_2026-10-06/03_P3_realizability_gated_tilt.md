# P3：可实现性门控的非对称倾斜（Realizability-Gated Asymmetric Tilt, RGT）（2026-10-06，v0.1，低先验）

> 一句话：把 $u$ 拆成负半边（压制无证据的断言，总是可实现）与正半边（提升证据支持的 token，只有全图学生能达到时才有意义）；负半边保持 β，正半边按"全图视图能否给该 token 非平凡概率"门控。不引入新前向。
> **先验最低**：它属于目标形状家族，本季在该家族里已有约 15 个负结果（含 floor、sup-only、X1）。只在 P1 结果出来之后决定是否做；若 P1 的 F3/F4 预检显示 $\mathcal F$ 外的强倾斜集中在证据实词上（硬翻转漏信号），P3 是自然的替代。

## 1. 痛点

- **教师修正学生看不见**（FP-OPD "Distill what the student can see"）：教师的修正有一部分落在学生视觉表征无法实现的方向上，强行拟合损害可实现部分；FP-OPD 的证据是完整教师目标（α=1）比插值目标（α=0.5）更难拟合、下游更差。
- **本仓库镜像探针**（`full_to_priv_probe_2026-10-05.md` §3.2）："看了但没看清"——全图前向的中层注意力已集中在 GT 框（活跃位 lift 均值 6），但注意力越集中的位置全图输出离特权输出越远。瓶颈是被注意区域的内容分辨率。
- **OPD-Aha 的 β 恰恰放大 $u$ 最大、即全图视图最难支撑的 token。** 它之所以仍有效，是因为学生可以**学会**从全图提取更多（ViCuR 的可恢复性）；但"当前不可达"的那部分正向信号，在当前 step 只能变成噪声。

## 2. 本仓库证据的支持与反对

| 支持 | 反对 |
|---|---|
| sup-only（只压不提）V\* 终点与 A 持平：负半边是 V\* 增益的主体，总是可实现 | sup-only 的 TB 丢关系推理：正半边不能整体去掉 |
| 机制结论 §1：A 学的是"证据不支持的话别说" | X1（出错后加强正半边）TB 反而掉：正半边的**剂量**不是答案 |
| OCR 丢分：文字 token 语言先验强、$u$ 略负，被过度压低 | 这说明问题也在负半边，RGT 不处理这一点 |

反对项说明 RGT 最多只能修正正半边的一部分，预期收益小。

## 3. 方法

$$u_t=u^+_t+u^-_t,\qquad u^+=\max(u,0),\ u^-=\min(u,0)$$

$$q_t\propto p^+_t\cdot\exp\!\big(\beta\,u^-_t+\beta\,g_t\odot u^+_t\big),\qquad g_t(v)=\sigma\!\Big(\frac{\log p^0_t(v)-\log\rho}{\kappa}\Big)$$

- 门控依据用 $p^0_t(v)$：null 视图（全图 + 空白块）下教师给该 token 的概率，即"全图视图本身能否支撑它"。$\rho$ 是可达阈值（建议 $\rho=10^{-3}$，略高于 top-100 尾部），$\kappa$ 控制软硬（$\kappa\to0$ 为硬门）。
- 直觉：若 $p^0(v)$ 非平凡，说明全图里有线索、只是不够清楚，学生能学；若 $p^0(v)\approx0$，全图里没有这个 token 的任何支撑，正向放大它只是在教学生"编一个看不见的细节"——这正是 case study 里 sup 家族的典型错误样态（`results_comparison_2026-10-02.md` §3.4：自信地编造不存在的细节）。
- 不用学生 $p^S$ 做门控：S 臂说明学生分布参照会混入"已学到的部分"，且随训练漂移；$p^0$ 来自冻结教师，稳定。

对照臂：$g\equiv1$ 即 A；$g\equiv0$ 即 sup-only。RGT 落在两者之间，但不是插值——它按 token 选择，而不是按剂量。

## 4. 实现落点

`core_algos.py` L1160–1167 的倾斜一行改为分半边，门控用 `teacher_null_distill_log_probs` 现成量；配置 `rgt_enable / rgt_rho / rgt_kappa`；守卫：与 `hist_*`、`u_clip_pos`、P1 互斥。指标：`rgt/gate_mean`、`rgt/pos_mass_kept`（正半边被保留的 $u$ 能量份额）、`rgt/target_tv`。测试：$\kappa\to0,\rho\to0$ 时与 A bit-identical；$\rho\to\infty$ 时与 sup-only bit-identical。

## 5. 离线预检

用 400 题探针 dump：在正半边 $u>0$ 的 token 上，画 $p^0(v)$ 的分布，看是否双峰（一簇接近 0、一簇非平凡）。若单峰且集中在 $10^{-4}$ 以下，门控几乎把正半边全部关掉，退化为 sup-only，不进训练。

## 6. 预测与 kill 条件

- 预测：V\* 与 A 持平；TB 的 Comparison / Contact 类（编造细节的错误样态）略升；Attributes 不掉。整体预期增益 ≤1 点，在噪声带内，需要池化 + 配对 bootstrap 才可判读。
- Kill：预检单峰；或训练后与 sup-only 同带。

## 7. 为什么仍值得记录

它是本季唯一一个把"目标形状"与一个**外部已被验证的痛点**（可实现性）直接对接的变体，且门控依据（$p^0$）是现成的；即使判负，也能回答"FP-OPD 的可实现性问题在特权自蒸馏里是否存在"。
